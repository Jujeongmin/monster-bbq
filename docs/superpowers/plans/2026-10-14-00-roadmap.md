# 몬스터 고깃집 로드맵

설계: [docs/superpowers/specs/2026-10-14-monster-bbq-design.md](../specs/2026-10-14-monster-bbq-design.md)

설계가 여러 하위 시스템으로 나뉘어서 계획을 단계별로 쪼갠다. 각 계획은 앞 계획이 끝난 뒤 그때의 코드를 보고 자세히 쓴다(미리 다 쓰면 앞 단계에서 바뀐 이름과 구조가 어긋난다). 각 계획은 끝나면 그 자체로 돌아가고 테스트되는 결과물을 남긴다.

| # | 계획 | 결과물 | 관문 |
|---|---|---|---|
| 01 | [사냥 손맛 검증](2026-10-14-01-hunt-feel.md) | 완료: 쿼터뷰 탑다운 + 데이브식 조준 사냥 시제품(설계 9장) | 사용자 결정 완료 |
| 02 | [뼈대](2026-10-14-02-foundation.md) (완료) | 하루 흐름 화면 전환(React), `shared/` 세이브 모델, 서버 뼈대(`npx -y @agent8/gameserver-node init`), `?local` 모드, 한국어·영어 i18n | 로컬 모드에서 세이브가 새로고침 후 유지 |
| 03 | [숲 사냥터 완성](2026-10-14-03-forest-hunt.md) (완료) | 몬스터 4유형(돌진·겁쟁이·원거리·무리), 부위 드롭, 채집, 가방, 서버 `startHunt`/`finishHunt` 검증 | 서버가 조작된 사냥 결과를 거부하는 테스트 |
| 03b | 동굴·늪 사냥터와 보스 | 03의 틀에 지역 2곳·보스 3마리 추가 | 보스 처치 → 페이지 회수 |
| 04 | [연구 주방과 메뉴](2026-10-14-04-kitchen.md) (완료) | 재료 조합 시도, 서버 전용 레시피 표, 힌트, 도감, 메뉴 고르기 | 레시피 정답이 클라이언트 번들에 없음 |
| 05a | [조리 장면](2026-10-14-05a-cook-stage.md) ([설계](../specs/2026-10-14-cooking-service-design.md)) | 불판·냄비 실제 조리(Phaser `CookStage`), 연구 주방이 조리 장면으로 | 연구 주방에서 굽고 끓여 레시피를 찾는다 |
| 05b | 장사와 정산 | 가게 단면도, 손님, 주문, 확대 전환, 도구 칩, 서빙, 서버 `startService`/`finishService`, 정산 | 하루 루프 한 바퀴가 끝까지 돈다 |
| 06 | 성장과 수익화 | 도시락, 업그레이드, 각성, 소환(천장·확률표), 황금 숯, VIP, VXShop 상품·효율 띠·상황형 패키지, 광고 4곳, 주간 랭킹 | `$onItemPurchased` 중복 지급 방지 테스트, 상품 등록표 `docs/vxshop-products.md` 승인 |
| 07 | 스토리와 연출 | 손자/손녀 선택, 대화·컷신 시스템, 프롤로그~3장 대사, 보스 일화, 엽서, 단서 | 대사 후보 승인 |
| 08 | 그림·소리·밸런스·출시 | PixelLab 실제 그림 교체(승인), Mixkit 소리, 밸런스 시뮬레이터, Verse8 연동(GitLab, `.env`, `.agent8.lock`), 출시 점검표 | 무과금/소과금/고래 진행 시뮬레이션 승인, 비공개 출시 |

그림 일정: PixelLab 월 할당은 2026-10-28에 충전된다. 01~06은 임시 그림(기존 테스트 에셋과 계정에 있는 캐릭터)으로 진행하고, 08에서 실제 그림으로 바꾼다. 그림이 일찍 필요하면 하루 보너스(최대 20회)를 쓴다.
