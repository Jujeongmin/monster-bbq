# 05a 조리 장면 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 불판과 냄비에서 손으로 굽고 끓이는 조리 장면(`CookStage`)을 만들고, 연구 주방이 버튼 대신 이 장면에서 요리를 시도하게 한다.

**Architecture:** 조리 물리는 순수 함수(`shared/cooking/grill.ts`, `pot.ts`)로, 시간 `dt`와 조작(올리기·뒤집기·옮기기·자르기·불판 갈기 / 넣기·다이얼·뚜껑·거품 걷기)을 받아 상태를 바꾸고, 담을 때 조리 정확도(0~1)와 솜씨 메모를 낸다. Phaser `CookStage` 장면은 그 상태를 그리고 끌기·탭·긋기를 조작으로 바꾼다. 연구 주방은 React 안에 이 장면을 띄우고, 접시에 담긴 재료와 도구의 조리법을 계획 04의 `cook` 행동으로 보낸다(판정은 그대로 서버). 정확도는 화면의 솜씨 한 줄에만 쓰고 서버로는 아직 보내지 않는다(장사 점수는 05b).

**Tech Stack:** TypeScript 5.7, Phaser 3.90, React 18, vitest 3.

**Spec:** [docs/superpowers/specs/2026-10-14-cooking-service-design.md](../specs/2026-10-14-cooking-service-design.md) (2·3·4장), 전체 설계 4장.

## Global Constraints

- 계획 02~04의 제약 전부(서버 판정, `t()` 문자열, 레시피 정답은 서버 전용, `npm run check:bundle` 통과).
- 그림은 Codex로 만들고 **사용자 승인 뒤에만** 장면에 넣는다. 코드로 그리지 않는다(익힘은 생·익은 그림 섞기와 색조, 효과는 Phaser 파티클로).
- 타이밍 단서는 눈에 보이는 것(색, 육즙 방울, 연기, 거품, 김)으로 준다. 막대 게이지를 정답 표시로 쓰지 않는다(냄비 다이얼 눈금은 실제 도구 모양이라 예외).
- 마우스와 터치가 같은 조작. 끌기 판정 반경은 넉넉하게(조각 반지름 + 10px).
- 무작위가 필요하면 연출에만(`Math.random`), 규칙은 결정적.

## Review Focus

- 아주 큰 `dt`(탭을 오래 숨겼다 돌아옴)에서도 상태가 깨지지 않는다: 장면은 `dt`를 50ms로 자르고, 규칙도 음수·NaN 없이 동작 → Task 2·3 테스트.
- 같은 아이템을 둘 올리거나 접시에 서로 다른 아이템을 4개 담으려 하면 막힌다(서버 `cook`이 거부할 시도를 화면이 만들지 않음) → Task 6 확인 + Task 2 테스트(`canPlate`).
- 불판 가장자리 밖에 놓으면 가장 가까운 불판 위로 붙는다 → Task 2 테스트.
- 그을린 불판을 갈면 다시 예열이 필요하다 → Task 2 테스트.
- 냄비를 끈 채 두면 식는다(익힘이 멈춤) → Task 3 테스트.

### Task 2: 불판 규칙

**Produces:** `shared/cooking/grill.ts`
- `GrillPiece { id; key: string; x; y; down: number; up: number; flips: number; cut: boolean; cutFace: number; cutEarly: boolean; stuck: boolean; char: number; fried: number; sootSeen: number }` — 좌표는 불판 중심 기준 반지름 1인 원 안, `down`은 불판에 닿은 면, `up`은 윗면 익힘(1 = 알맞음).
- `Grill { heat: number; soot: number; fat: number; pieces: GrillPiece[] }`, `newGrill()`(heat 0).
- `heatAt(x, y)`: 가운데 1, 가장자리 `edgeHeat`(0.45), 반지름 제곱으로 줄어듦.
- `stepGrill(g, dt)`: 예열(`preheatMs`), 닿은 면 익힘 += 재료 속도 × `heatAt` × `heat` × dt / `sideMs`, `burnAt` 넘으면 `char` 증가와 그을림 증가, 삼겹살이 익는 동안 기름(`fat`) 증가, 자른 조각의 단면 익힘, 기름 자리(불판 아래쪽 `y > 0.55`, `fat > 0.3`)의 마늘·버섯은 `fried` 증가, 조각마다 겪은 최대 그을림 `sootSeen`.
- 조작: `placePiece(g, id, key, x, y)`(원 밖이면 원 안으로 붙임, `heat < stickBelow`면 `stuck`), `flipPiece`, `movePiece`, `cutPiece`(덜 익었으면 `cutEarly`), `removePiece`(접시로), `replaceGrill`(그을림·기름 0, `heat`를 절반으로).
- `juicy(p)`: 닿은 면이 0.75 이상이고 윗면이 0.5 미만이면 참(육즙 방울 단서).
- `judgePiece(p): { accuracy: number; notes: NoteId[] }`.
- `canPlate(keys: string[], key: string)`: 서로 다른 아이템 ID 최대 3개.

**Consumes:** `ITEMS`, `parseItemKey`, `BALANCE.cooking`.

테스트(`shared/cooking/grill.test.ts`):
- 예열 전 올리면 `stuck`, 예열 후엔 아님.
- 가운데가 가장자리보다 빨리 익음.
- 목살이 삼겹살보다 느리게 익음, 꿀은 빨리 탐.
- 뒤집으면 면이 바뀌고 `flips` 증가.
- 오래 두면 `char`가 오르고 불판 `soot`가 오름. `replaceGrill` 후 그을림 0, 다시 예열 필요.
- 원 밖에 놓으면 원 안으로.
- 기름 자리에서 마늘 `fried` 증가(삼겹살 기름이 있을 때만).
- 덜 익은 채 자르면 `cutEarly`.
- `judgePiece`: 양면 알맞음 + 한 번 뒤집기 → 정확도 1에 가깝고 `perfect`, `onceFlip`. 탐 → `burnt`, 덜 익음 → `raw`, 들러붙음 → `stuck`, 세 번 이상 뒤집기 감점, 결과 0~1.
- 큰 dt(10초 한 번)와 작은 dt 여러 번이 비슷한 결과, 음수·NaN 없음.
- `canPlate`: 같은 ID 두 번 거부, 네 번째 ID 거부.

- [ ] 테스트 먼저 → 실패 확인 → 구현 → 통과 → 커밋 `feat(cooking): grill rules`

### Task 3: 냄비 규칙

**Produces:** `shared/cooking/pot.ts`
- `Pot { temp: number; dial: 0 | 1 | 2 | 3; lid: boolean; foam: number; skims: number; boilOvers: number; fullBoilMs: number; items: { key: string; cooked: number; order: number }[] }`, `newPot()`(20도, 끔).
- `stepPot(p, dt)`: 다이얼별 목표 온도(끔 20 → 식음, 약 96, 중·강 100)로 다가감(뚜껑 덮으면 빠름). 강불로 `boilOverMs`(뚜껑 덮으면 절반) 넘게 끓으면 `boilOvers` +1(넘침, 시간 초기화). 90도 이상이고 고기가 들어 있으면 거품 증가. 90도 이상일 때 재료 익힘(재료별 `potRate`).
- 조작: `addToPot(p, key)`, `setDial`, `toggleLid`, `skim`(거품 −`skimAmount`, `skims` +1).
- `judgePot(p): { accuracy; notes }`: 재료별 알맞음(채소는 1.5 넘으면 뭉개짐, 고기는 2.5까지 괜찮음), 남은 거품 감점, 넘침 감점, 거품을 걷어 맑으면 `clear`.

테스트(`shared/cooking/pot.test.ts`): 강불로 끓어오름, 끄면 식고 익힘이 멈춤, 뚜껑 덮으면 빨리 끓음, 강불로 오래 두면 넘침, 고기 넣고 끓이면 거품, 걷으면 줄어듦, 버섯을 너무 오래 끓이면 `mushy`, 맑은 국물 `clear`, 큰 dt 안전.

- [ ] 테스트 먼저 → 실패 확인 → 구현 → 통과 → 커밋 `feat(cooking): pot rules`

### Task 4: 솜씨 메모

**Produces:** `shared/cooking/notes.ts`: `type NoteId = "perfect" | "onceFlip" | "manyFlips" | "raw" | "burnt" | "stuck" | "soot" | "cutEarly" | "uncut" | "fatFried" | "clear" | "foamy" | "boilOver" | "mushy" | "undercooked"`, `plateResult(results: { accuracy; notes }[]): { accuracy; note: NoteId | null }`(정확도 평균, 대표 메모: 실수가 있으면 가장 큰 실수, 없으면 가장 좋은 칭찬). i18n `cook.note.<id>`(예: perfect "겉은 바삭, 속은 촉촉!", onceFlip "한 번만 뒤집었네, 정석이야", burnt "탄 맛이 난다…", stuck "불판에 들러붙었다", soot "그을린 불판 맛이 난다", clear "국물이 맑다", foamy "국물이 탁하다", boilOver "냄비가 넘쳤다", mushy "버섯이 뭉개졌다", fatFried "고기 기름에 구운 마늘, 최고지").

테스트: 평균, 실수 우선, 빈 목록.

- [ ] 테스트 먼저 → 실패 확인 → 구현 → 통과 → 커밋 `feat(cooking): cooking notes`

### Task 5: 조리 장면 — 불판

**Consumes:** Task 1 그림(승인 후), Task 2·4. **Produces:** `src/game/cook/CookStage.ts`(장면 키 `cook`), `init({ items: Record<string, number>; tools: ("grill" | "pot")[] })`, 끝나면 `game.events.emit("cook:plate", { keys: string[]; method: "grill" | "boil"; accuracy: number; note: NoteId | null })`.
- 화면(640×360): 가운데 왼쪽 큰 불판, 아래 재료 쟁반(가진 아이템 키마다 아이콘과 개수), 오른쪽 접시, 불판 옆에 집게(기본)와 가위, 위 왼쪽에 도구 고르기(불판/냄비).
- 조작: 쟁반에서 끌어 불판에 놓기, 불판 위 조각 끌어 옮기기, 탭하면 뒤집기(집게가 집어 뒤집는 짧은 동작), 가위를 탭해 들고 조각 위를 그으면 자르기(다시 탭하면 내려놓음), 조각을 접시로 끌면 담기, 깻잎처럼 굽지 않을 재료는 쟁반에서 접시로 바로, 그을린 불판은 오른쪽 위 "불판 갈기" 집게 동작(끌어서 치우기).
- 그리기: 윗면은 생·익은 그림을 윗면 익힘만큼 섞음, 닿은 면 익힘은 가장자리 색 테두리로, `juicy`면 육즙 방울, 익는 동안 연기 파티클과 기름 튐(열에 비례), 탄 정도는 어둡게, 자른 조각은 그림을 세 토막으로 잘라 그림, 예열 중엔 아지랑이, 불판 그을림은 어두운 얼룩, 기름 자리 반짝임.
- "완성": 접시에 하나 이상 있으면 눌림 → 이벤트.
- dt는 50ms로 자름.

확인: 브라우저에서 예열 → 삼겹살 올리기(들러붙음 확인을 위해 예열 전 한 번) → 육즙 방울 보고 뒤집기 → 자르기 → 마늘을 기름 자리에 → 접시 → 완성. 화면 캡처로 점검·수정.

- [ ] 작성 → `npx tsc --noEmit` → 브라우저 확인·수정 → 커밋 `feat(cooking): grill station`

### Task 6: 조리 장면 — 냄비

확인: 갈비찜(갈비 → 끓으면 거품 걷기 → 버섯 나중) 시도.

- [ ] 작성 → `npx tsc --noEmit` → 브라우저 확인·수정 → 커밋 `feat(cooking): pot station`
