# 08d 사냥 재설계 5단계 (돌진대왕의 굴) Implementation Plan

> **For agentic workers:** superpowers:executing-plans (inline). 출시 전이라 큰 검토자 에이전트는 돌리지 않는다(사용자, 2026-10-15). 테스트·타입 검사·실제 화면 확인으로 끝내고 푸시. 작업이 바뀔 때마다 사용자에게 "진행할까요?"(2026-10-16).

**Goal:** 1장 보스. 엄니대장을 처음 잡으면 굴 열쇠를 떨어뜨리고("돌진대왕 형님한테 이르지 마…"), 4층 이끼 동굴 아래 5층 **돌진대왕의 굴**이 열린다. 돌진대왕은 벽 돌진·낙석·새끼 부르기, 체력 절반 아래서 화난다. 처음 잡으면 노트 페이지가 돌아와 시그니처 요리 **숯불 왕갈비**가 열리고(연구 없이), 잡을 때마다 왕갈비(보스 고기). 매일 다시 도전할 수 있다.

**Architecture:** 층 정의에 5층(`needs: "key"`, 보스 한 마리, 출구 하나)을 더하고 4층 `down`을 연다. 보스 행동은 `shared/hunt/king.ts` 순수 상태 기계(엄니대장 `tusk.ts`와 같은 꼴). 세이브 v8에 `bossKey`·`pages`. 사냥 정산(`settleHunt`)이 엄니대장 처치에서 열쇠를, 돌진대왕 처치에서 페이지·요리 열림을 서버가 정한다. 새 요리·아이템(`king_galbi`, `king_rib`)은 그림이 없으면 비슷한 지금 그림으로 대신 보인다(그림은 파일만 넣으면 바뀜).

**Spec:** [hunt v3](../specs/2026-10-15-hunt-v3-depths-design.md) 3장(층 표 맨 아래), 5.4 5단계. [본 설계](../specs/2026-10-14-monster-bbq-design.md) 스토리(할머니의 시험, 보스 톤 대사).

## 결정 (사용자 2026-10-16, 셋 다 추천안)

- 열쇠: **엄니대장이 처음 잡힐 때 떨어뜨림.** 굴에 가려면 여전히 등불(4층)이 필요.
- 패턴: **① 벽 돌진**(길게 예고 → 직선 돌진, 벽에 박으면 3초 기절 = 빈틈, 피해 ×1.5·포획 기회) **② 낙석**(땅 구르기 → 그림자 원 예고 → 천장 돌) **③ 새끼 멧돼지 2마리 부르기.** 체력 50% 아래 화남(빠르게, 돌진 2연속). 체력 800.
- 보상: **처음 잡으면 노트 페이지 → 숯불 왕갈비 열림(레벨 1, 연구 없음)** + 대사. **매번 왕갈비**(별 등급 × 보스 배수 2: 쓰러뜨림 2개, 포획·수면 4개). 매일 도전, 지면(기력 0) 그날 사냥 끝(지금 규칙).

## 숫자 초안 (플레이로 조정)

- 5층: 기력 감소 초당 0.8, 넓이 1024×768(좁은 굴), 출구 1곳(도착 지점 옆 수레, 언제든 도망 가능), 몬스터는 돌진대왕만(새끼는 보고에 안 들어가고 아무것도 안 줌).
- 돌진대왕: 반지름 26, 접촉 피해 24. 돌진 예고 900ms·속도 260·벽 기절 3000ms·맞으면 피해 28. 낙석 예고 900ms·돌 5개(하나는 사냥꾼 자리)·반지름 26·피해 18. 새끼 체력 20·속도 120·피해 8, 동시에 최대 4마리. 패턴 사이 숨 고르기 1200ms. 화나면 속도 ×1.3, 돌진 2연속. 수면 10발.
- 서버: 돌진대왕 처치는 굴에 들어간 뒤 최소 25초(`minBossMs`).
- 숯불 왕갈비: 재료 왕갈비 + 마늘, 기본가 180, 조리 7초.

## Review Focus

- 열쇠 없이 `{ down: 5 }` 보고는 거부, 엄니대장을 잡은 보고면 열쇠가 생긴다(이미 있으면 그대로).
- 돌진대왕 처치 보고가 굴 도착 25초 안이면 거부.
- 처음 처치에서만 페이지·요리 레벨 1, 두 번째부터는 왕갈비만. 이미 강화한 요리 레벨은 안 내려간다.
- `research("king_galbi")`는 거부(페이지로만 열림).
- v7 세이브는 `bossKey: false, pages: []`로 읽힌다.
