# 데이브식 UI 재구성 Implementation Plan

> **For agentic workers:** superpowers:executing-plans (inline). 출시 전이라 큰 검토자 에이전트는 돌리지 않는다(사용자, 2026-10-15). 작업이 바뀔 때마다 사용자에게 "진행할까요?"(2026-10-16). Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 화면마다 다른 자원 막대를 데이브식 단계별 HUD(왼쪽 위 시간대·날짜, 오른쪽 위 골드·황금 숯, 오른쪽 아래 가방·수첩)로 바꾸고, 사냥·밤 장사 중에는 숨긴다. 보유 아이템은 가방 칸 격자로, 메뉴는 할머니 수첩 하나로 모으고, 밤 정산은 영수증 연출로 바꾼다.

**Architecture:** 무엇을 보일지는 순수 함수 모듈 `src/screens/hud/hud.ts`(테스트)가 정한다: `timeOfDay`, `bagRows`, `notebookApps`, `receiptLines`, `receiptAt`. 화면은 `DayHud`, `Bag`, `Notebook`, `Receipt`(모두 `src/screens/hud/`)이고 `DayFlow`가 단계에 따라 띄운다. 서버·세이브·행동은 바꾸지 않는다.

**Tech Stack:** TypeScript 5.7, React 18, vitest 3.

**Spec:** [데이브식 UI 재구성 설계](../specs/2026-10-16-dave-ui-design.md)

## Global Constraints

- 글은 전부 `t()`(ko·en). 새 창·버튼은 UI 키트 그림(`ui-panel`, `ui-frame`, `ui-slot`, `ui-sq`, `ui-bar`, `ui-plate`, `ui-btn`, `ui-tab`)으로 만들고 CSS 색 상자로 만들지 않는다.
- 새 그림은 승인 전엔 대신 쓰는 그림(설계 8장). 그림 경로는 한 곳(`hud.ts`의 `HUD_ART`)에 모아 파일만 바꾸면 바뀌게 한다.
- 크기는 `--s` 배율 단위로 쓴다(`calc(Npx * var(--s))`).
- 작업마다 커밋. 마지막 작업에서 `docs/VERSE8.md` 점검표를 돌린다.

### Task 1: 무엇을 보일지 (순수 함수)

**Files:** Create `src/screens/hud/hud.ts`, `src/screens/hud/hud.test.ts`

**Interfaces (Produces):**

```ts
export type Phase = "hunt" | "lunch" | "kitchen" | "service" | "settle";
export type TimeOfDay = "morning" | "noon" | "afternoon" | "evening" | "night";
export function timeOfDay(phase: Phase, huntPeriod: "morning" | "afternoon" | null): TimeOfDay;
export function showDayHud(phase: Phase, hunting: boolean): boolean; // 사냥 중·밤 장사 중 false
export type BagTab = "part" | "forage" | "material";
export interface BagCell { key: string; id: ItemId; premium: boolean; count: number }
export function bagRows(items: Record<string, number>, tab: BagTab): BagCell[];
export type App = "bag" | "upgrade" | "awaken" | "cookbook" | "menu" | "shop";
export function notebookApps(phase: Phase): { app: App; open: boolean }[];
export interface ReceiptLine { key: StringKey; vars: Record<string, number | string>; gold?: number }
export function receiptLines(s: LastService, reputation: number): { lines: ReceiptLine[]; total: number };
export function receiptAt(ms: number, lineCount: number, total: number): { shown: number; total: number; done: boolean };
```
