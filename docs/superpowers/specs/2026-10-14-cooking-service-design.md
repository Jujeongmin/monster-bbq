# 조리와 장사 설계 (2026-10-14)

[전체 설계](2026-10-14-monster-bbq-design.md) 4장의 "조리 도구별 탭 한 번" 조작을 이 문서로 바꾼다. 사용자 결정(2026-10-14): 요리는 버튼식이 아니라 생동감 있고, 실제 요리를 좋아하는 사람이 알아볼 디테일이 들어간다. 연구 주방과 밤 장사가 같은 조리 장면을 쓴다. 장사 화면은 확대 전환식이고 사용자 친화적으로 만든다.

## 1. 목표

- 조리 하나하나가 "진짜 이렇게 한다"는 느낌: 손으로 집고, 보고, 판단한다. 정답 타이밍은 눈에 보이는 단서(색, 육즙, 거품, 김)로 알려 주고 막대 게이지에 기대지 않는다.
- 정석 동작(한 번만 뒤집기, 거품 걷기, 넣는 순서)을 하면 점수가 오르고, 실수(탐, 들러붙음, 끓어넘침)는 깎인다.
- 마우스와 터치가 같은 조작(끌기, 탭, 긋기, 돌리기). 판정은 넉넉하고 놓을 자리에 붙는다.

## 2. 조리 도구

### 불판 (굽기, 처음부터)

| 디테일 | 동작 | 점수 |
|---|---|---|
| 예열 | 장사·연구 시작 시 불판이 달궈진다. 아지랑이 연기가 오르면 준비 완료 | 덜 달군 불판에 올리면 들러붙음(감점, 육즙 손실) |
| 올리기 | 재료 쟁반에서 집게로 끌어다 불판에 놓는다. 치익 소리·연기·기름 튐 | — |
| 불판 온도 | 가운데가 가장 뜨겁고 가장자리는 덜 뜨겁다. 끌어서 옮긴다 | 익은 고기를 가장자리로 옮기면 타지 않고 보온 |
| 뒤집기 | 고기를 탭하면 집게로 뒤집는다. 윗면에 육즙이 맺히고 가장자리 색이 올라오면 뒤집을 때 | 한 번만 뒤집으면 보너스, 세 번 이상은 감점 |
| 자르기 | 가위를 집고 고기 위를 그으면 한입 크기로 잘린다 | 덜 익은 채 자르면 육즙 손실. 자른 단면은 잠깐 더 구워야 함 |
| 고기 기름 | 삼겹살 기름이 불판 낮은 쪽으로 흐른다 | 마늘·버섯을 기름 자리에 구우면 곁들이 보너스 |
| 재료 차이 | 목살은 두꺼워 오래, 갈비·꿀 바른 고기는 당분 때문에 빨리 탄다, 버섯은 물이 나온다 | 재료별 익힘 속도·탐 기준 |
| 그을림 | 탄 조각과 기름이 쌓여 불판이 그을린다. 불판 갈기(끌어서 치우기) | 그을린 불판에서 구우면 쓴맛(감점). 갈면 잠시 다시 예열 |
| 소금 (사용자 결정 2026-10-14) | 소금통을 들고 고기 위에서 흔든다(한 번 흔들 때마다 한 꼬집) | 굽기 전에 미리 치면 겉면 수분이 빠져 마이야르가 잘 일어나 겉이 진하게 구워짐(보너스). 구운 뒤에 치면 효과 적음, 너무 많이 치면 짜다(감점) |
| 레스팅 (사용자 결정 2026-10-14) | 다 구운 고기를 옆 나무 도마로 옮겨 잠시 둔다 | 고기 속(심부) 익힘은 겉보다 늦게 따라온다. 도마에서 쉬면 잔열로 속까지 고르게 익음(보너스). 쉬지 않고 바로 담거나 자르면 속이 덜 익어 감점. 두꺼운 고기(목살·닭다리)일수록 차이가 큼, 얇은 삼겹살은 작음. 불판 위에서 잘라 단면을 구워도 속이 빨리 익음 |
| 담기 | 다 익은 조각을 접시로 끌어다 놓는다. 깻잎처럼 굽지 않는 재료는 쟁반에서 접시로 바로 | — |

### 냄비 (끓이기, 1장 끝에 해금. 연구 주방에서는 처음부터)

| 디테일 | 동작 | 점수 |
|---|---|---|
| 넣는 순서 | 재료를 끌어 넣는다. 오래 걸리는 것(뼈 붙은 고기, 닭) 먼저, 버섯·채소 나중 | 재료마다 알맞은 익힘 시간. 채소를 너무 오래 끓이면 뭉개짐 |
| 불 조절 | 다이얼을 돌린다(끔·약·중·강). 센불로 끓이고 끓어오르면 줄인다 | 강불로 계속 두면 끓어넘침(감점) |
| 거품 | 끓기 시작하면 불순물이 떠오른다. 국자로 그어 걷어 낸다 | 맑은 국물 보너스, 남은 거품은 감점 |
| 뚜껑 | 탭해서 덮기/열기. 덮으면 빨리 끓지만 안이 안 보이고 넘치기 쉽다 | — |
| 담기 | 국자로 떠서 그릇에 | — |

### 나중 도구 (해금될 때 구현)

- **웍(볶기, 2장)**: 기름에 마늘 먼저 볶아 향 내기(너무 오래면 탐), 좌우로 끌어 흔들어 재료 넘기기, 센불 유지.
- **튀김기(튀기기, 2장 끝)**: 반죽 한 방울로 기름 온도 확인(바로 떠오르면 적온), 거품이 잦아들면 건지기, 두 번 튀기면 바삭 보너스.
- **도마(무치기, 3장)**: 일정한 리듬으로 칼질, 원을 그리며 조물조물(너무 오래면 숨이 죽음).

## 3. 점수

- **조리 정확도(0~1)** = 익힘 점수 × 정석 보너스 − 실수 감점, 0~1로 자른다.
- **요리 점수** = 조리 정확도 × 고기 등급 배율(특급이 높음).
- 서버는 조리 과정을 볼 수 없다. 정확도는 클라이언트가 보고하고(고기 등급과 같은 위험 수용, 전체 설계 7장), 서버는 범위(0~1)와 소요 시간·재료를 검사한다.
- 결과에는 솜씨 한 줄을 붙인다(예: "겉은 바삭, 속은 촉촉!", "한 번만 뒤집었네, 정석이야", "국물이 맑다").

## 4. 연구 주방

- 같은 조리 장면을 쓴다. 도구(불판·냄비)를 고르고, 장면 아래 재료 쟁반에서 재료를 끌어다 조리하고 접시에 담아 "완성"을 누른다.
- 접시에 담긴 재료(서로 다른 아이템 최대 3개, 하나씩) + 쓴 도구의 조리법이 서버로 가고, 서버가 표로 판정한다(계획 04의 `cook` 행동 그대로).
- 연구 주방은 해금과 상관없이 구현된 도구를 전부 쓸 수 있다(실험이니까). 메뉴에는 가진 도구의 요리만 올라간다(계획 04).
- 결과 창: 판정 결과(새 레시피 / 아는 맛 / 힌트 / 망한 요리) + 솜씨 한 줄.

## 5. 밤 장사

- **화면**: 평소엔 가게 단면도(손님, 테이블, 주문 말풍선과 인내심). 주문을 탭하면 그 요리의 조리 도구로 확대 전환.
- **확대 화면에서도 놓치지 않게**:
  - 위쪽 주문표: 기다리는 손님의 요리 그림과 인내심.
  - 오른쪽 도구 칩: 익힘 링, 타기 직전 깜빡임과 소리, 탭하면 그 도구로 이동.
  - 자리를 비워도 음식은 계속 익는다(현실감). 대신 알림을 확실히 준다.
- **첫 안내**: 처음 하는 동작마다 뚜껑이가 한 번 짧게 알려 준다(예: "육즙이 맺히면 뒤집어!"). 대사는 임시, 계획 07에서 승인.
- **일시정지**: 혼자 하는 게임이라 둔다.
- **흐름**: `startService(menu)` → 서버가 장사 ID와 손님 시드(손님 수는 평판·날짜) → 손님 입장·주문 → 조리(재료 쟁반: 메뉴 재료와 개수, 특급/보통 선택) → 접시를 주문표의 손님에게 끌어 서빙 → 화나서 떠나면 평판 감소 → 마감 → `finishService` → 정산(매출, 팁, 만족도, 평판 변화).
- **서버 검사(`finishService`)**: 손님이 시드에 있음, 요리가 오늘 메뉴, 쓴 재료를 실제로 가짐(특급 포함), 정확도 0~1, 최소 소요 시간, 같은 장사 ID 중복 처리 금지. 통과하면 서버가 재료 차감, 골드·평판 지급.
- 세이브에 `service`(진행 중인 장사), `reputation` 추가.

## 6. 구조

- 조리 규칙: `shared/cooking/grill.ts`, `shared/cooking/pot.ts`(순수 함수, vitest). 불판 온도 분포, 앞뒷면 익힘, 뒤집기 횟수, 자르기, 탐, 그을림 / 수온, 불 세기, 끓어넘침, 거품, 재료별 익힘. 수치는 `BALANCE.cooking`.
- 장면: Phaser `CookStage`(연구·장사 공용), `ServiceScene`(가게·손님·주문, 05b).
- 그림(Codex, 승인 후 사용): 위에서 본 불판, 부위별 생/익은 재료, 집게·가위·국자, 냄비와 국물 상태(맑음·거품), 다이얼, 접시·그릇 / (05b) 가게 단면도, 손님 4종. 익어 가는 모습은 생·익은 그림을 섞고 그을림을 겹친다.
- 소리: Mixkit(지글거림, 보글보글, 가위). 내려받기는 사용자 허락 후, 계획 08 또는 그 전에 따로.

## 7. 범위

- **05a 조리 장면**: 불판·냄비, 연구 주방이 조리 장면으로 바뀜.
- **05b 장사**: 가게, 손님, 주문, 서빙, 도구 칩, `startService`/`finishService`, 정산.
- **도시락**은 계획 06으로 옮긴다.
