# 성장과 수익화 설계 (초안, 승인 대기 — 2026-10-14)

[전체 설계](2026-10-14-monster-bbq-design.md) 5장을 구현할 수 있게 숫자와 순서를 정한 초안이다. **표의 숫자는 전부 제안이며 사용자 승인 전에는 구현하지 않는다.** 원칙(전체 설계 5장, CLAUDE.md): 소수 고액 결제자의 IAP만 본다, 무료 유저 완주 보장 안 함, 광고 수익 0 기준, VX 상품의 효율 띠는 실제 값으로만 계산.

## 1. 범위 나누기 (제안)

- **06a 골드 성장**: 장비 업그레이드(사냥에 실제 효과), 주방·가게 업그레이드(메뉴 슬롯, 도구 해금·품질, 냉장고, 좌석), 도시락. 결제 없음. 하루 루프가 "번 돈으로 강해지는" 순환을 갖게 한다.
- **06b 결제 성장**: 황금 숯, 동료와 소환(확률 공개·천장), 각성(별 1~20), VIP, VXShop 상품·효율 띠·상황형 패키지, 광고 4곳, 주간 랭킹.
- 이유: 06b의 소비처(각성·소환)가 06a의 장비·도구 위에 얹히기 때문. 06a만 끝나도 게임 한 바퀴가 성장한다.

## 2. 06a 골드 성장 (제안 숫자)

| 분야 | 단계 | 효과 | 비용(골드) |
|---|---|---|---|
| 근접 무기 | 1→4 | 피해 10 → 14 → 19 → 26 | 300 / 900 / 2,400 (+보스 재료, 03b) |
| 원거리 무기 | 1→3 | 피해 5 → 8 → 12, 사거리 +10% | 400 / 1,500 |
| 방어구 | 1→4 | 최대 체력 100 → 130 → 170 → 220 | 300 / 1,000 / 2,800 |
| 가방 | 12→24칸 | +3칸씩 | 200 / 500 / 1,000 / 2,000 |
| 메뉴 슬롯 | 2→5 | +1 | 400 / 1,200 / 3,000 |
| 조리 도구 | 냄비·웍·튀김기·도마 | 장 진행으로 해금 + 골드 | 600 / 1,500 / 3,000 / 5,000 |
| 도구 품질 | 1→3 | 판정 구간 +15%씩(예: 탐 기준이 늦어짐) | 도구마다 500 / 2,000 |
| 좌석 | 4→8 | 하룻밤 손님 +1 | 800 / 1,600 / 3,200 / 6,400 |
| 도시락 통 | 1→3칸 | 사냥에 요리 들고 가기(회복·버프) | 300 / 1,500 |

- 기준: 1장에서 하룻밤 매출 100~250골드. 1장 끝까지 근접 2·방어구 2·메뉴 3·냄비를 살 수 있는 정도(무과금 약 2시간).
- 도시락: 연구로 찾은 요리를 사냥 전에 1~3개 챙김. 먹으면(사냥 중 버튼) 회복 또는 짧은 버프(예: 삼겹살 구이 = 체력 +40, 꿀 토끼다리 = 10초 이동 +20%). 요리 점수가 효과 크기에 곱해짐.

## 3. 06b 결제 성장 (제안 숫자)

### 황금 숯

- VX로만 산다(광고·업적으로 아주 조금). 가치 기준: **100 VX = 30숯**(가장 작은 묶음).
- 쓰는 곳: 각성(별 11~20), 소환, 시간 단축(없음: 우리 게임은 대기 시간이 없다).

### 동료 (12종: 일반 4, 희귀 4, 영웅 2, 전설 2)

- **사냥 동료**: 길들인 몬스터가 같이 싸움(예: 멧돼지 동료가 돌진으로 몰이).
- **주방 동료**: 조리를 거든다(예: 불판 한 칸 자동 뒤집기, 냄비 거품 자동 걷기, 판정 구간 확대). 요리 게임 손맛을 해치지 않게 "한 칸·한 가지"만 돕는다.
- 동료 이름·모습·성격은 스토리라 07에서 후보 승인(06b는 번호와 능력만).

### 소환 (확률 게임 안 공개 — 한국 게임산업법)

| 등급 | 확률 | 천장 |
|---|---|---|
| 전설 | 1% | 100회째 확정(천장은 소환 횟수로 서버가 셈) |
| 영웅 | 5% | 10연마다 영웅 이상 1개 보장 |
| 희귀 | 25% | |
| 일반 | 69% | |

- 1회 30숯, 10연 270숯. 중복은 그 동료의 각성 재료(조각).

### 각성 (무기·방어구·도구·동료마다 별 1~20, 별마다 능력치 ×1.1)

- 별 1~10: 골드 위주 + 숯 소량(별마다 5~40숯).
- 별 11~20 숯: 120, 160, 200, 260, 320, 380, 460, 540, 560, 600 = **3,600숯(= 12,000 VX)** — 전체 설계의 "하나를 별 20까지 약 12,000 VX".
- 각성 대상 20개(장비 3 + 도구 5 + 동료 12) × 3,600숯 = 72,000숯 ≈ **240,000 VX** → 100만 원(≈70,000 VX)을 써도 소비처가 남는다(전체 설계: 15만 VX 이상).

### VIP (전체 설계 5장 그대로)

100 / 500 / 1,500 / 3,000 / 6,000 / 12,000 / 25,000 / 45,000 / **70,000** / 100,000 VX. 숯 묶음 보너스 최대 +25%, 일일 보상, 전용 외형, 랭킹에 표시. 결제 웹훅에 가격이 없어서 서버가 상품별 VX 표로 누적(낮밤용사와 같은 방식).

## 4. VXShop 상품 (제안 — 효율 띠는 아래 계산식만 씀)

**효율 = 내용물 가치 ÷ 가격**, 내용물 가치는 숯 환산(30숯 = 100 VX). 숯이 아닌 내용물은 아래처럼 정한 값으로만 환산한다.

| Product ID | 이름 | 가격 | 내용물 | 가치 계산 | 효율 띠 |
|---|---|---|---|---|---|
| `starter_pack` | 스타터팩 | 100 | 희귀 주방 동료 1 + 숯 200 + 골드 3,000 (계정당 1회) | 희귀 이상이 나올 때까지 평균 소환 3.2회 = 97숯 + 숯 200 = 297숯 = 990 VX (골드는 계산에서 뺌) | **효율 990%** |
| `premium_pass` | 프리미엄 패스 | 1,000 | 광고 없이 광고 보상 + 메뉴 슬롯 +1 + 숯 300 (영구, 계정당 1회) | 광고 없이 500 VX(단품 기준가) + 슬롯 500 VX + 숯 300 = 1,000 VX → 2,000 VX | **효율 200%** |
| `season_pass` | 시즌 패스 | 400 | 2주 패스 줄: 숯 480 + 한정 외형 | 숯 480 = 1,600 VX (외형은 계산에서 뺌) | **효율 400%** |
| `charcoal_1` | 숯 주머니 | 100 | 숯 30 | 기준 | 100% (첫 구매 2배: 200%) |
| `charcoal_2` | 숯 자루 | 500 | 숯 180 | +20% | 120% (첫 구매 240%) |
| `charcoal_3` | 숯 상자 | 1,500 | 숯 600 | +33% | 133% (첫 구매 267%) |
| `charcoal_4` | 숯 가마 | 5,000 | 숯 2,250 | +50% | 150% (첫 구매 **300%**) |
| `charcoal_5` | 숯 대장간 | 30,000 | 숯 15,000 | +67% | 167% (첫 구매 333%) |
| `pack_ch1_boss` | 숲 보스 패키지 | 2,000 | 보스에게 진 직후 24시간: 숯 900 + 영웅 동료 선택권 | 숯 900 = 3,000 VX + 영웅 선택권(영웅 이상 평균 16.7회 = 500숯 = 1,667 VX) | **효율 233%** |

- 상황형 제안: 보스에게 졌을 때(24시간 한정), 소환 천장 10회 남았을 때 안내, 랭킹 마감 6시간 전 경쟁자와의 차이, 새 장 출시 기념.
- 지급은 서버 `$onItemPurchased`만, 같은 `purchaseId` 한 번만(관문 테스트). 클라이언트 `onClose`는 화면 갱신만.
- 등록표는 승인 뒤 `docs/vxshop-products.md`(낮밤용사 형식)로.

## 5. 광고 4곳 (전체 설계 그대로)

정산 매출 2배(하루 1회), 쓰러짐 부활(사냥 1회당 1번), 연구 힌트(하루 2회), 장사 전 손님 +3(하루 1회). 프리미엄 패스면 광고 없이 받음. 서버가 `requestId`로 중복·한도 검사.

## 6. 주간 랭킹

주간 최고 하룻밤 매출(06b), 보스 최단 처치(03b 이후). 시즌(2주) 1~3위 한정 외형. Global Collection.

## 7. 정해 줄 것

1. 06a / 06b로 나누기
2. 06a 업그레이드 표의 숫자(나중에 시뮬레이터로 조정)
3. 소환 확률과 천장(전설 1%, 100회 천장, 10연 영웅 보장)
4. 주방 동료가 "한 칸·한 가지"만 돕는 방향
5. VXShop 상품 구성과 효율 띠 계산 방식(특히 프리미엄 패스 = 광고 없이 + 메뉴 슬롯 + 숯)
