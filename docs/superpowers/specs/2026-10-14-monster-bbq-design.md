# 몬스터 고깃집 설계 (2026-10-14)

Verse8용 쿼터뷰(탑다운) 몬스터 사냥 + 한식 요리 게임. 데이브 더 다이브식 하루 루프(낮 사냥 → 저녁 연구 주방 → 밤 장사 → 정산)를 따른다. 요리 게임 인식과 몬스터 사냥 손맛을 둘 다 강하게 가져간다. 수익은 소수 고액 결제자의 IAP만 본다.

이 문서의 결정은 2026-10-14 대화에서 사용자가 섹션별로 승인했다.

## 1. 목표와 전제

- 플랫폼: Verse8 웹게임. PC와 모바일 모두 지원. 화면은 **가로형**.
- 조작(2026-10-14 손맛 검증 중 변경): **사냥은 데이브 더 다이브식 직접 조작.** PC는 WASD/방향키 이동 + 마우스 조준(좌클릭 작살, 우클릭 베기). 모바일은 왼쪽 가상 조이스틱 + 오른쪽 화면을 눌러 조준하고 떼면 작살 발사 + 베기 버튼. 가게·주방·메뉴 화면은 클릭/탭.
- 톤: 코믹하고 아기자기. 데이브 더 다이브처럼 웃기고 따뜻하게.
- 그림: PixelLab 픽셀아트, 게임에 넣기 전에 사용자 승인. Kenney·itch.io·OpenGameArt 금지. 소리는 Mixkit.
- 기간보다 완성도. 1차 출시는 3장까지(7장 참고).
- 언어: 한국어 + 영어. 처음부터 번역 구조를 깐다.
- 수익: IAP만 본다. 광고 수익은 0으로 본다. 무료 유저가 끝까지 가는 것은 보장하지 않는다.

## 2. 핵심 루프와 진행

하루는 네 단계다.

1. **낮 · 사냥터**: 쿼터뷰 사냥. 고기 부위와 채집 재료를 모은다. 체력이나 가방이 다 차면 귀환한다.
2. **저녁 · 주방**: 연구 주방에서 레시피를 시도하고, 오늘 팔 메뉴를 고른다. 도시락을 챙긴다.
3. **밤 · 장사**: 가게 단면도에서 주문을 받아 조리 도구별로 만들어 서빙한다.
4. **정산**: 매출, 만족도, 평판 변화를 보여 주고 업그레이드로 넘어간다.

진행은 두 축이 서로 밀어준다.

- **사냥 축**: 무기, 방어구, 가방 업그레이드로 더 깊은 사냥터와 보스를 연다.
- **요리 축**: 레시피와 조리 도구가 늘어 비싼 메뉴를 판다.
- 좋은 재료는 사냥 실력이, 좋은 장비는 요리로 번 돈이 필요하다.
- 장마다 **보스**가 있고 보스 고기는 그 장의 **시그니처 요리** 재료다. **장 클리어 = 보스 처치 + 시그니처 요리 완성.** 이 지점에서 스토리가 진행된다.
- 레시피 도감은 수집 목표로 둔다(진행 축은 아님).

## 3. 사냥

### 사냥터와 시점 (2026-10-14 손맛 검증에서 결정)

- **쿼터뷰 탑다운**(MMORPG처럼 위에서 비스듬히 내려다보는 시점, 참고: 도깨비의세계·바람의 나라). 도트 캐릭터, 사방 8방향 자유 이동. 벨트스크롤과 플랫폼형도 시제품으로 만들어 비교했고 사용자가 탑다운을 골랐다.
- 사냥터는 화면보다 큰 맵이고 카메라가 사냥꾼을 따라 위아래좌우로 움직인다. 나무·덤불·바위는 지나갈 수 없다. 화면 아래쪽에 있는 것이 앞에 그려진다(y 정렬).
- 귀환 버튼으로 언제든 귀환. 체력 0이면 가방 재료 일부를 잃고 강제 귀환(광고 부활 가능, 5장).

### 조작 (데이브 더 다이브식)

- 이동: PC는 WASD/방향키, 모바일은 왼쪽 가상 조이스틱. 사방 8방향.
- **작살(원거리)**: PC는 마우스로 조준해 좌클릭, 모바일은 오른쪽 화면을 눌러 조준하고 떼면 발사. 화면 어디로든 날아가 처음 닿은 몬스터에 꽂히고 **끌어당긴다**. 끌려온 몬스터는 약 1.7초 기절(카운터 기회).
- **베기(근접)**: PC는 우클릭, 모바일은 베기 버튼. 조준 방향의 **부채꼴**(좌우 60°) 사거리 안 몬스터를 모두 맞힌다. 베기마다 한 걸음 전진한다. 쿨타임 중 누른 입력은 기억했다가 바로 나간다(선입력).
- PC에서 사냥꾼은 항상 마우스 쪽을 바라본다.
- 몬스터는 공격 전 **예고 동작**(빨간 번쩍임 + 돌진 경로에 빨간 화살표 줄)을 한다. 돌진은 예고할 때 노린 방향으로 직진하므로 옆으로 비켜서 피한다.
- 기본 흐름: 작살로 끌어와서 → 기절한 몬스터를 3타 콤보(카운터)로 마무리 → 특급 고기.
- 무기 단계: 근접(식칼 → 도끼 → … 4단계), 작살(3단계).

### 손맛 (던파식 요소를 탭으로)

- **3타 콤보**: 같은 대상을 계속 근접 공격하면 1타 → 2타 → 3타 막타(1.8배, 크게 날려 보냄). 원거리는 콤보 없음.
- **카운터**: 돌진 직후 헐떡이는 몬스터를 때리면 1.5배.
- **백어택**: 몬스터가 바라보는 반대쪽에서 때리면 1.25배.
- **연출**: 히트스톱(약 0.06초, 막타·카운터는 2배), 넉백, 흰색 번쩍임, 막타·카운터 때 화면 흔들림, 데미지 숫자와 "카운터!"·"백어택!"·"막타!" 글자.
- 스킬 버튼 2~3개(쿨타임)는 손맛 검증 결과를 보고 계획 03에서 정한다.

### 몬스터

- 행동 유형: 겁쟁이형(도망), 돌진형(예고 후 돌진), 원거리형(침·가시), 무리형.
- 사냥터마다 유형을 섞고, 끝에 패턴이 있는 보스를 둔다.

### 전리품과 연결 장치

- 몬스터는 **부위**를 떨어뜨린다(예: 멧돼지 → 삼겹, 목살, 갈비). 보스는 시그니처 부위.
- 반짝이는 풀·버섯을 탭하면 1초 동안 채집(채소, 양념류).
- 가방은 칸 수 제한, 업그레이드로 증가.
- **고기 등급**: 마지막 일격이 근접이고 그 몬스터에 원거리 명중이 2회 이하면 **특급**, 그 외는 **보통**. 등급이 요리 점수와 가격에 곱해진다(배율은 밸런스 표).
- **도시락**: 사냥 전에 만든 요리 1~3개를 챙긴다. 먹으면 회복이나 버프.

## 4. 요리

### 연구 주방 (레시피 발견)

- 재료 최대 3개 + 조리법 1개(굽기, 끓이기, 볶기, 튀기기, 무치기)를 골라 시도한다.
- 결과: **성공**(새 레시피, 연출, 도감 등록) / **아깝게 실패**(힌트. 예: "고기는 맞는데 국물이 있어야 할 것 같아…") / **완전 실패**(웃긴 망한 요리).
- 시도할 때마다 고른 재료를 하나씩 쓴다(성공·실패 무관).
- 도감에는 못 찾은 요리가 실루엣과 힌트 한 줄로 보인다. 관련 재료를 처음 얻으면 힌트가 열린다.
- 힌트는 뚜껑이가 말한다(6장).

### 메뉴 고르기

- 장사 전에 메뉴 슬롯 수만큼 오늘 메뉴를 고른다. 가진 재료로 몇 인분이 나오는지 보여 준다.

### 밤 장사

- 가게 단면도. 손님(코믹한 몬스터 주민)이 앉으면 말풍선에 요리 아이콘과 인내심 게이지가 뜬다.
- 주문을 탭하면 해당 조리 도구로 간다.

> **2026-10-14 변경:** 아래 표의 탭 한 번 조작은 [조리와 장사 설계](2026-10-14-cooking-service-design.md)로 바뀌었다(생동감 있는 실제 조리, 확대 전환식 장사, 연구 주방도 같은 조리 장면).

| 조리 도구 | 조작 |
|---|---|
| 불판 (굽기) | 색이 변하면 탭해서 뒤집기 → 다 익으면 가위로 자르기 탭 → 서빙. 늦으면 탄다 |
| 냄비 (끓이기) | 게이지가 초록 구간일 때 탭해서 불 끄기 |
| 웍 (볶기) | 연타로 타기 전에 게이지 채우기 |
| 튀김기 (튀기기) | 노릇한 타이밍에 탭해서 건지기 |
| 도마 (무치기) | 움직이는 표시가 칸에 맞을 때 세 번 탭 |

- 도구마다 칸 1~2개로 시작, 업그레이드로 증가. 주문이 쌓이면 여러 도구를 오간다.
- 완성 요리를 탭하면 서빙. **요리 점수 = 조리 정확도 × 고기 등급.** 팁과 만족도가 점수로 정해진다. 화나서 떠난 손님은 평판을 깎는다.
- 장사 길이는 손님 수 기준.

## 5. 경제와 수익화

### 재화

- **골드**: 장사로 번다. 기본 업그레이드와 장비 제작.
- **황금 숯**(가칭, 유료 재화): VX로 사고 광고·업적으로 소량 받는다. 각성, 소환, 시간 단축.
- **평판**: 쌓이는 수치. 손님 수와 손님 등급(비싼 주문, 특별 손님)을 올린다.
- **재료**: 냉장고 칸 수만큼 보관. 상하지 않는다(1차).

### 업그레이드

| 분야 | 항목 |
|---|---|
| 사냥 | 근접 무기 4단계, 원거리 무기 3단계, 방어구 4단계, 가방, 도시락 통(1 → 3칸) |
| 주방 | 조리 도구 해금(장 진행 + 골드), 도구 칸 수, 도구 품질(판정 구간 확대), 메뉴 슬롯, 냉장고 |
| 가게 | 좌석(하룻밤 손님 수) |

- 높은 단계 장비는 보스 재료가 필요하다(예: 도끼 = 돌진대왕 엄니).

### 결제로 강해지는 구조

- **각성**: 무기, 방어구, 조리 도구, 동료마다 별 1~20. 별마다 능력치 ×1.1. 별 1~10은 골드 위주 + 숯 소량, **별 11~20은 숯 위주**. 장비 하나를 별 20까지 약 12,000 VX 상당.
- **동료 소환(뽑기)**: 사냥 동료(길들인 몬스터, 같이 싸움)와 주방 동료(판정 구간 확대 또는 한 칸 자동 조리). 등급 일반·희귀·영웅·전설.
  - 1회 30숯(≈100 VX), 10연 270숯(≈900 VX). 전설 1%, **천장 100회**.
  - **확률표를 게임 안에 공개한다**(한국 게임산업법, 2024-03 시행 의무).
  - 소환과 확률 판정은 서버에서 한다.
- 전체 소비처는 15만 VX를 크게 넘게 설계한다(100만 원을 써도 남아 있게).

### 경쟁과 과시

- **주간 랭킹 2종**: 주간 최고 매출(하룻밤 매출 최고치), 보스 최단 처치(그 주의 지정 보스 1종). 시즌(2주) 1~3위에게 한정 외형.
- **VIP 누적(VX)**: 1단계 100 / 2단계 500 / 3단계 1,500 / 4단계 3,000 / 5단계 6,000 / 6단계 12,000 / 7단계 25,000 / 8단계 45,000 / **9단계 70,000(약 100만 원)** / 10단계 100,000. 단계별 영구 혜택(숯 묶음 보너스 최대 +25%, 일일 보상)과 전용 외형. 랭킹 화면에 VIP 등급과 외형이 보인다.

### VXShop 상품 (초안, 100 VX ≈ $1)

| 상품 | 가격 (VX) | 비고 |
|---|---|---|
| 스타터팩 | 100 | 계정당 1회. 초반 동료 + 숯. 체감 가성비 약 10배 |
| 프리미엄 패스 | 1,000 | 광고 없이 광고 보상, 배속, 숯. 영구, 계정당 1회 |
| 시즌 패스 | 400 | 2주마다. 한정 외형 |
| 황금 숯 묶음 5종 | 100 / 500 / 1,500 / 5,000 / 30,000 | 30 / 180 / 600 / 2,250 / 15,000숯(VX당 +0 / +20 / +33 / +50 / +67%). 묶음마다 첫 구매 2배 |
| 기간 한정 패키지 | 2,000~10,000 | 새 장 출시, 주말 특가. 기간·횟수 제한 |

- **효율 강조 띠**: 모든 상품에 "효율 200%", "효율 300%" 같은 띠를 크게 단다. 숫자는 **실제 내용물 가치 ÷ 가격**을 기본 숯 묶음(100 VX = 30숯) 대비로 계산한 값만 쓴다(부풀리면 표시광고법 위험).
- 상품 등록표는 `docs/vxshop-products.md`로 따로 만들어 승인받는다(낮밤용사 형식).
- 지급은 서버 `$onItemPurchased`에서만. 같은 `purchaseId`는 한 번만 지급. 클라이언트 `onClose`는 화면 갱신만.

### 광고 (`@verse8/ads`)

수익원이 아니라 잔류와 프리미엄 패스 미끼. 보상은 작게. 프리미엄 패스가 있으면 광고 없이 받는다.

| 위치 | 보상 | 제한 |
|---|---|---|
| 정산 | 오늘 매출 2배 | 하루 1회 |
| 사냥 중 쓰러짐 | 그 자리 부활, 가방 유지 | 사냥 1회당 1번 |
| 연구 주방 | 레시피 힌트 1개 | 하루 2회 |
| 장사 전 | 손님 +3 | 하루 1회 |

- 버튼을 눌렀을 때만 광고. 보상은 서버가 `requestId`로 중복·한도를 검사한 뒤 준다.

### 결제 깔때기와 밸런스 기준

| 구간 | 설계 의도 | 유도 상품 |
|---|---|---|
| 1장 ~ 2장 초반 (1~2시간) | 결제 없이 재미를 느끼는 미끼 구간 | 없음 |
| 1장 보스 직후 | 첫 결제 문턱 낮추기 | 스타터팩 |
| 2장 보스 | 첫 번째 벽(무과금은 여러 번 실패) | 프리미엄 패스, 시즌 패스, 실패 직후 한정 패키지 |
| 3장 이후 | 결제 전용 성장 구간. 3장 보스 요구 전투력 ≈ 무과금 최대치 × 1.6 | 숯 묶음, 소환, 각성 |
| 상시 | 고래의 계속 결제 동기 | 주간 랭킹, VIP, 기간 한정 패키지 |

상황형 제안: 보스에게 졌을 때 그 보스용 한정 패키지(24시간), 소환 천장이 가까울 때 남은 횟수, 랭킹 마감 직전 경쟁자와의 차이, 새 장 출시 기념 패키지.

모든 가격·수치는 `shared/`의 밸런스 표 한 곳에서만 관리하고, 세부 수치는 시뮬레이터(무과금 / 소과금 / 고래 진행 속도)로 맞춘 뒤 사용자 승인을 받는다.

## 6. 스토리: 할머니의 비법 노트

### 시작

- 취업에 계속 떨어지던 손주(처음에 **손자/손녀 선택**)에게 할머니의 편지와 열쇠가 온다. "가게는 너한테 맡긴다. 노트는 네가 찾아라. 할미는 바쁘다."
- 시골 마을 외곽의 먼지 쌓인 **'할매 돌판집'**. 부뚜막의 무쇠 솥뚜껑이 깨어나 잔소리를 시작한다. 할머니의 오랜 주방 동료 **뚜껑이**(잔소리꾼, 츤데레, 연구 주방 힌트 담당).
- 비법 노트는 표지만 남고 페이지가 빠져 있다.

### 전개: 할머니의 시험

- 할머니는 페이지를 각 지역의 **옛 숙적이자 친구인 보스들**에게 맡겼다. "이 녀석을 잡을 실력이 되면 이 요리를 만들 자격이 있다."
- 보스를 쓰러뜨리면 페이지를 돌려주며 할머니 일화를 하나씩 들려준다. 시그니처 요리를 완성하면 장이 끝나고 할머니의 행방 단서가 쌓인다.
- 일화들을 모으면 할머니가 평생 이기지 못한 상대가 하나 있었다는 공통점이 드러난다.

### 장 구성

| 장 | 사냥터 | 보스 | 시그니처 요리 | 출시 |
|---|---|---|---|---|
| 1 | 숲 | 돌진대왕 멧돼지 | 숯불 왕갈비 | 1차 |
| 2 | 동굴 | 버섯 골렘 | 버섯 전골 | 1차 |
| 3 | 늪 | 거대 장어 | 장어 양념구이 | 1차 |
| 4 | 설산 | 서리 곰 | 서리 수육 | 업데이트 |
| 최종 | 화산 | 전설의 용 | (대결 요리) | 업데이트 |

### 할머니는 사실 엄청 강하다 (직접 말하지 않는다)

- 게임 안에서 누구도 "할머니는 강하다"고 말하지 않는다. 그 얘기만 나오면 다들 말을 돌린다. 손주 본인만 끝까지 "우리 할머니는 그냥 요리를 잘하시는 거야"라고 믿는다.
- 숨은 설정: 할머니는 이 일대 몬스터들이 본능적으로 피하는 존재. 보스들은 할머니에게 한 번씩 크게 혼난 사이. 용과의 **99번째 요리 대결**(98전 49승 49패)은 용이 할머니와 싸우지 않으려고 제안한 체면 세우기이고, 49승은 할머니가 용의 자존심을 지켜 주려고 맞춰 준 숫자다. 엔딩 분위기로만 느끼게 한다.

| 언제 | 단서 |
|---|---|
| 가게 첫 방문 | 벽의 거대한 뿔과 비늘 방패. 뚜껑이: "아, 그거? 할미가 장 보러 갔다가 주워 온 거야." |
| 첫 무기 | 할머니의 식칼은 손주가 들지도 못할 만큼 무겁다. 뚜껑이: "할미는 그걸로 파 썰었는데." |
| 숲 사냥터 | 산을 일직선으로 가른 골짜기. 뚜껑이: "예전에 할미가 장작 패다가 좀." |
| 1장 보스전 | 돌진대왕이 가게 앞치마를 보고 움찔. 쓰러진 뒤: "…그 할망구한텐 3초도 못 버텼는데, 넌 꽤 오래 걸리는구나." |
| 손님 대사 | 할머니 얘기만 나오면 목소리를 낮추고 아무도 값을 깎지 않는다. "여기서 값 깎던 놈이 하나 있었는데… 요즘 안 보이더라." |
| 장 사이 엽서 | "용이 또 졌다고 삐져서 하루 더 있다 간다. 가게 불 꺼뜨리지 마라." |
| 보스 일화들 | 칭찬하다가 중간에 떤다. "아니 뭐, 무섭다는 게 아니라… 존경한다는 거지." |
| 엔딩 | 대결 직전 용이 손주에게: "이번엔… 너희 할머니가 너무 진지하지 않게 좀 말려 줄 수 있겠니?" |

### 결말 (업데이트)

화산 꼭대기에서 할머니와 용의 99번째 대결. 할머니는 이번 결판을 위해 손주를 수셰프로 키우려고 시험을 냈다. 할머니와 손주가 함께 용과 요리 대결을 하고, 이기면 용이 단골이 된다("맛있어서"라고 하지만 표정은 겁먹어 있다).

### 반복 인물

뚜껑이, 마을 이장님(첫 손님, 튜토리얼), 장마다 늘어나는 단골 몬스터 손님들.

스토리 세부(대사, 이름, 컷신)를 새로 정할 때는 후보를 여러 개 보여 주고 승인받는다.

## 7. 기술 구조

### 폴더와 역할

| 위치 | 역할 |
|---|---|
| `src/` (React) | 화면과 UI: 메뉴판, 연구 주방, 도감, 업그레이드, 상점, 랭킹, 대화, 확률표 |
| `src/game/` (Phaser 3) | 사냥 장면(쿼터뷰 탑다운), 장사 장면(가게 단면도) |
| `src/net/` | 서버·광고·VXShop 연결은 여기에만 둔다 |
| `src/i18n/` | 한국어·영어 문자열 |
| `shared/` | 순수 게임 규칙: 밸런스 표, 몬스터, 장비, 각성 비용, 정산 계산, 검증 한계. 서버와 클라이언트가 함께 쓴다 |
| `server/src/` | Verse8 서버(`export class Server`). 핸들러 파일은 `server/src/` 바로 아래 |

### 서버 판정 흐름 (클라이언트 값은 믿지 않는다)

1. **사냥**: `startHunt` → 서버가 사냥 ID와 몬스터 배치 시드를 준다. `finishHunt(huntId, 결과)` → 배치에 있던 몬스터인지, 최소 소요 시간, 가방 용량, 장비로 가능한 처치 속도, 고기 등급 비율 상한을 검사한 뒤 재료를 준다.
2. **연구 주방**: 재료 + 조리법을 받아 재료를 차감하고 결과를 판정한다. **레시피 표는 서버에만 둔다.** 클라이언트는 힌트만 받는다.
3. **장사**: `startService(menu)` → 메뉴 재료를 예약하고 손님 배치 시드를 준다. `finishService(serviceId, 주문별 점수)` → 손님 수, 재료 소모, 점수 상한, 소요 시간을 검사한 뒤 골드·평판을 주고 랭킹을 갱신한다.
4. **업그레이드·각성·소환**: 비용 차감과 결과 결정을 서버가 한다.
5. **결제**: `$onItemPurchased`만 지급. `purchaseId` 중복 지급 방지.
6. **광고 보상**: `requestId`로 중복·한도 검사.

모든 변경은 계정 단위 `$lock` 안에서 한다. 사냥·장사 ID로 같은 결과를 두 번 처리하지 않는다(재시도 안전).

### 저장 (CLAUDE.md 규칙 3과 다른 결정)

- 규칙 3은 재화를 `$asset`에 두라고 하지만, **재화를 포함한 세이브 전체를 Global User State 하나에 두고 `$lock` 안에서 `updateMyState` 한 번으로 바꾼다**(2026-10-14 사용자 결정).
- 이유: 공식 문서상 `$lock`은 순서만 맞출 뿐 중간 실패 시 앞의 저장을 되돌리지 않고, `$asset`은 저장이 5초 묶음으로 늦게 반영된다. 각성(숯 차감 + 별 증가)처럼 둘이 같이 바뀌어야 하는 처리가 반쯤 반영되면 고액 결제자 분쟁으로 이어진다. 유저 상태도 클라이언트는 읽기만 가능하고 쓰기는 서버만 해서 조작 위험은 `$asset`과 같다.
- 랭킹은 Global Collection(주간 단위). 결제 처리 기록은 세이브 안에.
- 다른 유저가 내 상태를 읽을 수 있으므로 세이브에 개인 정보를 넣지 않는다.

### 개발과 검증

- `?local` 모드: 서버 코드를 브라우저 안에서 그대로 돌린다(개발 빌드만).
- 테스트: `shared/`는 vitest, 서버는 `gameserver-node test`.
- 밸런스 시뮬레이터: 무과금 / 소과금 / 고래 진행 속도와 벽 위치 확인.
- 오류 처리: 요청 중 버튼 잠금, 실패 시 재시도, 연결 끊김 배너. 사냥·장사 결과는 서버가 받았다고 확인할 때까지 보관했다가 다시 보낸다.

## 9. 손맛 검증 결과 (2026-10-14)

계획 01에서 시제품 네 가지를 차례로 만들어 사용자가 비교했다.

| 시제품 | 결과 |
|---|---|
| 벨트스크롤 + 탭 이동·자동 공격 | 조작이 간접적이라 이상하다(사용자) |
| 벨트스크롤 + 키보드·조이스틱 → 데이브식 조준 | 시점이 데이브 느낌과 다르다 |
| 플랫폼형(중력·점프·발판) | 별로다(사용자) |
| **쿼터뷰 탑다운 + 데이브식 조준** | **채택.** 참고: 도깨비의세계 카메라 |

- 결정: 사냥은 쿼터뷰 탑다운, 기본 해상도 640×360(캐릭터가 화면 높이의 약 11%), 맵 1536×1024.
- 조작: PC는 WASD + 마우스 조준(좌클릭 작살, 우클릭 베기), 모바일은 조이스틱 + 오른쪽 눌러 조준·떼면 발사 + 베기 버튼.
- 손맛 흐름: 작살로 맞혀 끌어오기 → 1.7초 기절 → 베기 3타(카운터 15·15, 막타 27) → 특급 고기. 베기는 한 걸음 전진하고 쿨타임 중 입력은 기억했다 나간다.
- 돌진 예고: 빨간 번쩍임 + 돌진 경로의 어두운 띠·빨간 테두리·흘러가는 빨간 화살표(반투명 빨강은 풀밭에서 갈색으로 보여 실패).
- 맵: 풀밭 타일 + 시드로 흩어 놓은 나무·덤불·바위(밑동만 충돌, 가리면 잎 반투명). 그림은 Codex로 생성.
- 수치는 `shared/balance.ts`(작살 사거리 170·속도 340, 멧돼지 체력 60·돌진 190, 기절 1700ms 등).
- 다음 계획에 넘길 것: 쿼터뷰용 사냥꾼(손자/손녀)·몬스터 그림, 스킬 버튼 여부(설계 3장), 몬스터 4유형 중 나머지 3유형, 그림 예산 재계산(4방향).
