# 사냥 개편 (hunt v2) — 포획 사냥 설계

> 상태: 설계 1/3·2/3·3/3 사용자 승인(2026-10-15). 다음은 writing-plans(가게 개편 07a 다음 순서).
> 원작 참고: 데이브 더 다이버의 잠수·포획. 조사 요약은 이 문서 끝.
> 이 문서가 [전체 설계](2026-10-14-monster-bbq-design.md) 3장의 "고기 등급"과 몬스터 행동 부분을 대신한다. 시점(쿼터뷰 탑다운)과 조작(WASD + 마우스 조준, 모바일 조이스틱 + 누르고 떼서 작살 + 베기 버튼)은 그대로.

## 1. 왜 바꾸나 (2026-10-15 사용자)

- 지금 전투가 "짜친다": **할 게 단조롭고**(끌어와서 베기만 반복), **그림·사냥터가 싸 보인다**. 시점·조작감은 문제로 고르지 않았다.
- 방향(3안 중 선택): **A 포획 사냥** — 데이브 더 다이버처럼 "어떻게 잡느냐가 곧 보상". 사냥터 탐험(깊이·시간·무게)과 주문 사냥은 나중에 이 위에 얹을 수 있다.

## 2. 잡는 방법과 별 등급 (설계 1/3)

| 별 | 잡는 방법 | 재료 |
|---|---|---|
| ★ | **쓰러뜨리기**: 식칼(우클릭) 3타 콤보·카운터·백어택 그대로, 체력 0 | 보통 1개 |
| ★★ | **포획**: 작살(좌클릭)로 끌어온 뒤 포획 게이지를 연타로 채움 | 보통 2개 |
| ★★★ | **재우기**: 수면 작살로 재운 뒤 옆에서 E로 담기 | 특급 2개 |

- 지금의 "근접 막타면 특급" 규칙은 없앤다.
- **포획 게이지**: 작살이 맞으면 지금처럼 끌어오고, 몬스터가 버둥거리며 게이지가 뜬다. PC = 좌클릭 또는 Space 연타, 모바일 = 화면 아무 데나 탭. 몬스터 체력이 많이 남을수록 게이지가 빨리 준다 → "식칼로 살짝 약하게 → 작살"이 정석, 너무 때리면 쓰러져 ★. 실패하면 줄이 끊기고 화난다(겁쟁이는 도망). 설정에 "자동 연타".
- **작살 빗맞힘**: 줄이 감기는 약 0.6초 동안 다시 못 쏜다.
- **수면 작살**: Q(모바일은 팁 버튼)로 작살 팁 기본 ↔ 수면. 수면 팁은 끌어오지 않고 맞힐 때마다 졸음 게이지가 차서, 다 차면 몇 초 뒤 잠든다. 잠든 동안 맞으면 깬다. 처음엔 없고 **업그레이드로 연다**.
- **서버 검증**: 사냥 보고에 몬스터마다 {쓰러뜨림 / 포획 / 재움}. 서버는 seed로 진짜 몬스터·한 번씩·시간을 확인하고, 수면 팁을 열지 않았는데 "재움"이면 거부, 방법마다 최소 시간(포획 = 게이지 시간, 재움 = 잠드는 시간)을 둔다. 별을 속이는 것은 이 상한으로만 묶는다(지금 특급 판정과 같은 수준). 재료 수·등급은 서버가 별로 계산한다.

## 3. 몬스터 성향과 우두머리 (설계 2/3)

| 몬스터 | 성향 | 행동 | 잡기 특징 |
|---|---|---|---|
| 토끼 | 안 덤빔 | 다가가면 도망, 궁지에 몰리면 잠깐 얼어붙음 | 체력이 적어 식칼 한 방에 ★가 되기 쉬움. 포획·수면 1발이 쉬운 대신 빨라서 맞히기 어려움 |
| 닭 | 맞으면 반격(무리) | 평소엔 쪼아 먹음, 하나를 건드리면 무리 전체가 쪼러 옴 | 무리 중 하나를 몰래 재우면 나머지는 눈치 못 챔. 식칼은 무리를 부름 |
| 벌 | 닿으면 아픔 + 원거리 | 벌집 근처를 맴돌며 침, 몸에 닿아도 아픔 | 근접은 위험 → 작살·수면이 정석. 포획 게이지 중에도 침이 날아옴 |
| 멧돼지 | 먼저 덤빔 | 보이면 예고(빨간 번쩍임 + 화살표) 후 돌진, 돌진 뒤 헐떡이는 빈틈 | 빈틈에 카운터로 약하게 → 포획. 수면 2~3발 |

- **우두머리 "엄니대장"**(사용자 선택, 3안 중): 사냥마다 1마리(서버 seed가 여부·위치를 정함), 덩치 큰 멧돼지. 큰 엄니를 자랑하는 동네 골목대장 — 보스 돌진대왕의 부하 느낌. 등장 카드 "이 구역 대장이다!", 잡히면 "돌진대왕 형님한테 이르지 마…".
  - 패턴: ① 연속 돌진 3번 ② 땅 구르기(둥근 범위 예고 → 충격파) ③ **들이받아 깔아뭉개기**(붙잡기 → 연타 탈출, 늦으면 큰 피해). 큰 패턴 뒤 약 2초 헐떡임 = 공격 기회.
  - 보상은 일반 멧돼지의 2배(★ 보통 2, ★★ 보통 4, ★★★ 특급 4). 수면 5발, 깨면 화나서 빨라짐.
  - 1장 보스 돌진대왕은 03b 계획대로 따로. 엄니대장은 매일 나오는 중간 강적.
- **배치**: seed로 성향이 다른 무리를 섞는다(예: 닭 무리 옆 벌집, 그 사이를 도는 멧돼지) → "조용히 재울까, 다 깨울 각오로 칠까".
- **숫자 초안(플레이로 조정)**: 포획 게이지 2~4초, 수면 발수 토끼·닭·벌 1 / 멧돼지 2~3 / 엄니대장 5, 엄니대장 체력 = 멧돼지 ×4.

## 4. 연출·UI·업그레이드·그림 (설계 3/3)

- **손맛 연출**: 포획 중 줄이 팽팽하게 떨리고 몬스터가 버둥, 둥근 포획 게이지(연타마다 튀고 화면 살짝 흔들림), 성공 시 "포획!" 도장 + ★★ 튀어 오름. 수면은 머리 위 졸음 게이지 → 비틀 → 털썩 + Zzz 말풍선, 담으면 ★★★ + 반짝이. 담은 재료가 사냥꾼 머리 위에서 가방 아이콘으로 날아감. 엄니대장 등장 이름 카드 컷인(약 1.5초, 탭 건너뛰기) + 화면 위 체력 막대, 붙잡기 때 큰 연타 표시. 귀환 정산에 별 등급별로 줄 세우기. 소리(Mixkit): 작살 발사, 줄 감기, 버둥, 포획 성공, 코골이, 우두머리 등장. 히트스톱·넉백·데미지 숫자는 그대로.
- **화면 표시**: 작살 팁 표시(PC 오른쪽 아래 + Q, 모바일 팁 버튼), 일시정지 메뉴에 자동 연타.
- **업그레이드**: 새 "수면 팁" 1단계 열기 → 2·3단계 졸음이 빨리 참(초안 800 / 2,000 / 4,500골드). 작살 업그레이드는 그대로 + 단계마다 포획 게이지가 조금 쉬워짐.
- **가게와 연결**: 가게 개편(restaurant v2)의 특급 재료 = ★★★ 재료. 가게 규칙은 바뀌지 않는다.
- **그림**: 가게처럼 **그림 1픽셀 = 게임 2픽셀**(사냥터 그림을 절반 해상도로, 카메라 2배). 코덱스로 구도 → 진짜 픽셀 변환. 다시 그릴 것: 사냥꾼(8방향 걷기 — 옆모습 발 교차 고치기, 베기, 작살, 포획 버티기, 담기), 몬스터 4종(걷기, 예고, 버둥, 잠, 쓰러짐), 엄니대장, 사냥터 타일·나무·바위. 동작이 많아 PixelLab 충전(2026-10-28) 이후. 그림마다 승인.

## 5. 진행 순서

1. 가게 개편 1단계(07a, 계획 완성).
2. **사냥 1단계**: 별 등급·포획·수면·몬스터 성향·엄니대장 규칙과 서버 검증, 지금 그림으로 손맛 연출 → 배포.
3. **사냥 2단계**: 사냥 그림 전체 새로(그림마다 승인) → 배포.

## 6. 테스트

- 공용 규칙 단위 테스트: 별 → 재료 개수·등급, 수면 팁 없이 "재움" 거부, 방법별 최소 시간, 엄니대장 보상 2배, 같은 seed = 같은 엄니대장.
- 서버 하네스(실행 전 사용자에게 알림).
- 브라우저 직접 플레이(PC·모바일).

## 부록: 데이브 더 다이버 조사 요약 (2026-10-15)

- 별 등급: ★★★ = 그물·수면·드론 회수, ★★ = 작살로 끌어오기, ★ = 무기로 죽이기(고기 최소).
- 작살 명중 → 체력이 남으면 연타 게이지, 실패 시 놓침. 팁마다 입력 방식이 다름(연타·돌리기·타이밍). 자동 연타 옵션이 접근성 패치로 추가.
- 빗맞힌 작살은 줄이 감기는 동안 무방비.
- 물고기 성향 4가지(비공격, 선공, 후공, 접촉 피해) + 도망·무리. 깊을수록 위험.
- 큰 패턴 뒤 긴 빈틈, 붙잡기 → 연타 탈출. 보스는 이름 카드 컷신.
- 비판받은 점(조준 중 이동 불가, 위아래 사각, 두 버튼 동시 조작)은 우리 조작이 이미 피함.
