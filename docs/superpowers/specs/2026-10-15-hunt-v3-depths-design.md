# 사냥 재설계 (hunt v3) — 깊이 내려가는 숲 설계

> 상태: 설계 1/3·2/3·3/3 사용자 승인(2026-10-15). **1단계(뼈대: 층·기력·출구·하루 두 번) 구현됨**(계획 08a, 2026-10-15). 다음은 2단계(무기).
> 원작 참고: 데이브 더 다이버의 잠수(산소·무게·수심 구역·장비 업그레이드·작살·총·포획).
> 이 문서가 [사냥 개편(포획)](2026-10-15-hunt-v2-capture-design.md)을 대신한다. 그 문서의 별 등급·포획 게이지·엄니대장은 여기 4장으로 옮겨 살린다.
> [전체 설계](2026-10-14-monster-bbq-design.md)의 사냥 한 판·하루 흐름·성장(업그레이드) 부분도 이 문서가 대신한다. 시점(쿼터뷰 탑다운)은 그대로.

## 1. 왜 바꾸나 (2026-10-15 사용자)

- 사냥과 업그레이드를 이 게임의 **메인 콘텐츠**로. 데이브 느낌을 많이 살린다. 필요하면 조작·배경·몬스터를 전부 바꾼다.
- 중심 재미(4안 중 선택): **깊이 들어가는 탐험** — 버틸 시간과 가방이 정해져 있고, 깊이 갈수록 위험하고 비싸다. 언제 돌아올지 고민하는 긴장감. 업그레이드는 더 깊이 가기 위한 것.
- 시점: 데이브는 옆모습이라 "아래 = 깊이"가 저절로 생기지만 우리는 쿼터뷰라 깊이를 층으로 만든다. 조작(WASD + 마우스 조준)은 데이브와 거의 같으므로 유지(사용자 질문에 대한 답, 2026-10-15).

## 2. 정한 것 (사용자 결정, 각 후보 중 선택)

| # | 질문 | 결정 |
|---|---|---|
| 1 | 중심 재미 | 깊이 들어가는 탐험 |
| 2 | 깊이 구조 | **층으로 내려가기**(쿼터뷰 유지, 층마다 지도) |
| 3 | 산소 역할 | **기력 = 시간 + 체력**(게이지 하나) |
| 4 | 귀환 | **출구까지 가야 귀환** |
| 5 | 층 열기 | **장비로 열기**(데이브의 잠수복) |
| 6 | 업그레이드 비용 | **골드 + 깊은 층 재료** |
| 7 | 무기 | **작살 + 보조무기 고르기 + 식칼** |
| 8 | 별 등급 | **넣기**(잡는 방법 = 보상) |
| 9 | 하루 사냥 횟수 | **낮 2번**(아침·오후) |
| 10 | 지도 방식 | **고정 지형 + 매번 바뀌는 몬스터**(서버 seed) |
| 11 | 늪 몬스터 | **개굴장군, 물뱀** |
| 12 | 동굴 몬스터 | **박쥐 무리, 반딧버섯게** |

## 3. 하루 흐름과 사냥 한 판 (설계 1/3)

- **하루**: 아침 사냥 → 점심 주방(도시락·장비 바꾸기·업그레이드) → 오후 사냥 → 저녁 주방(연구·메뉴판) → 밤 장사. 아침과 오후는 나오는 몬스터가 조금 다르다(예: 닭은 아침, 박쥐는 해 질 녘).
- **사냥 한 판(5~8분)**: 늘 숲 입구(1층)에서 시작. 층마다 아래로 내려가는 길이 있고, 그 층에 맞는 장비가 없으면 막혀 있다.
- **기력**: 시간이 가면 줄고 맞아도 준다. 깊은 층일수록 빨리 준다. 도시락을 먹으면 찬다(데이브의 산소통 줍기). 0이 되면 쓰러져 가방의 절반을 잃고 집으로(지금의 기절 규칙).
- **출구**: 층마다 몇 군데(반달이가 세워 둔 수레). 깊을수록 적고 멀다. 출구에서 E로 귀환.
- **가방**: 칸 수 한도(데이브의 무게). 깊은 층 재료(광석·가죽)는 1개가 2칸.
- **1장 숲의 층(이름은 가제)**:

| 층 | 이름 | 필요 장비 | 나오는 것 |
|---|---|---|---|
| 1 | 숲 입구 | 없음 | 토끼·닭·버섯·마늘·깻잎 |
| 2 | 깊은 숲 | 없음 | 멧돼지·벌, 엄니대장(가끔) |
| 3 | 안개 늪 | 장화 | 개굴장군·물뱀, 늪 재료 |
| 4 | 이끼 동굴 | 등불 | 박쥐 무리·반딧버섯게, 철광석 |
| 맨 아래 | 돌진대왕의 굴 | 보스 열쇠 | 1장 보스(03b) |

- **지도**: 층마다 손으로 짠 고정 지형(길·출구·숨은 곳·명소). 몬스터·채집물·희귀 몬스터는 서버 seed로 매번 바뀐다.
- **그림**: 층마다 배경 한 장(Codex 구도 → 진짜 픽셀), 그림 1픽셀 = 게임 2픽셀.

## 4. 무기·장비·업그레이드 (설계 2/3)

### 4.1 조작

| 행동 | PC | 모바일 |
|---|---|---|
| 이동 | WASD | 조이스틱 |
| 작살 | 좌클릭 | 오른쪽 화면 누르고 떼기 |
| 보조무기 | 우클릭 | 보조무기 버튼 |
| 식칼 | Space | 베기 버튼 |
| 줍기·담기·출구 | E | 행동 버튼 |
| 도시락 | 1·2·3 | 도시락 칸 |

식칼이 우클릭에서 Space로 옮긴다(CLAUDE.md의 사냥 조작 줄도 고친다).

### 4.2 별 등급 (사냥 개편 설계에서 옮김)

| 별 | 잡는 방법 | 재료 |
|---|---|---|
| ★ | 쓰러뜨리기(식칼 3타 콤보·카운터·백어택, 새총) | 보통 1개 |
| ★★ | 포획: 작살로 끌어온 뒤 연타로 포획 게이지 채우기 | 보통 2개 |
| ★★★ | 재우기(수면총) 후 E로 담기, 또는 그물총 포획 | 특급 2개 |

- 포획 게이지: PC = 좌클릭 또는 Space 연타, 모바일 = 화면 탭. 몬스터 체력이 많이 남을수록 게이지가 빨리 준다 → "식칼로 살짝 → 작살"이 정석. 실패하면 줄이 끊기고 화난다(겁쟁이는 도망). 설정에 "자동 연타".
- 작살 빗맞힘: 줄이 감기는 약 0.6초 동안 다시 못 쏜다.
- 지금의 "근접 막타면 특급" 규칙은 없앤다.

### 4.3 작살 (늘 들고 감)

끌어오기 → 포획(★★). 강화하면 피해·사거리가 오르고 포획 게이지가 조금 쉬워진다.

### 4.4 보조무기 (출발 전에 하나 골라 감, 한 판마다 탄 수 제한)

| 무기 | 하는 일 | 별 |
|---|---|---|
| 새총 | 멀리서 약하게 때려 기절 | 식칼로 마무리하면 ★ |
| 수면총 | 맞힐 때마다 졸음이 차고 다 차면 잠듦, 옆에서 E로 담기. 잠든 동안 맞으면 깸 | ★★★ |
| 그물총 | 작은 몬스터 바로 포획, 큰 몬스터는 잠깐 묶기 | ★★★ |
| 폭죽 | 무리를 흩고 멧돼지를 놀라게 함 | — |

보조무기는 재료로 만들고 강화한다(탄 수·위력).

### 4.5 장비

| 장비 | 하는 일 |
|---|---|
| 장화 | 안개 늪으로 내려갈 수 있음, 늪에서 안 느려짐 |
| 등불 | 이끼 동굴로 내려갈 수 있음, 단계마다 더 멀리 보임 |
| 기력 통 | 기력 최대치 증가(데이브의 산소통) |
| 가방 | 칸 증가 |
| 도시락통 | 도시락 칸 증가 |
| 앞치마 갑옷 | 받는 피해 감소 |

### 4.6 비용과 깊은 층 재료

- 비용 = 골드 + 깊은 층 재료(먹지 못하는 재료). 늪: 개구리 가죽·뱀 비늘. 동굴: 게 껍데기·빛버섯·철광석(동굴 벽 캐기).
- 예: 등불 1단계 = 600골드 + 개구리 가죽 3개 → 늪에서 가죽을 모아 와야 동굴이 열린다. 숫자 표는 계획 때 승인받는다.
- 지금 업그레이드(식칼·작살·갑옷·가방·도시락통)는 새 장비로 옮기고 산 단계는 이어받는다. 사라지는 것은 쓴 골드를 돌려준다.

### 4.7 몬스터

| 층 | 몬스터 | 성향·잡기 특징 | 재료 |
|---|---|---|---|
| 1 | 토끼 | 다가가면 도망, 궁지에 몰리면 잠깐 얼어붙음. 체력이 적어 식칼 한 방에 ★가 되기 쉬움 | 토끼 다리 |
| 1 | 닭(무리) | 하나를 건드리면 무리가 쪼러 옴. 몰래 재우면 나머지는 눈치 못 챔 | 닭 다리·가슴살 |
| 2 | 벌 | 벌집 근처를 맴돌며 침, 몸에 닿아도 아픔. 포획 게이지 중에도 침이 날아옴 | 벌집 |
| 2 | 멧돼지 | 예고 후 돌진, 돌진 뒤 헐떡이는 빈틈 → 카운터로 약하게 → 포획 | 삼겹살·목살·갈비 |
| 2 | 엄니대장(가끔) | 덩치 큰 멧돼지 우두머리, 연속 돌진·땅 구르기·깔아뭉개기(연타 탈출). 보상 2배, 수면 5발. 등장 카드 "이 구역 대장이다!", 잡히면 "돌진대왕 형님한테 이르지 마…" | 멧돼지 재료 ×2 |
| 3 | 개굴장군 | 큰 개구리. 혀로 끌어당김(연타 탈출). 혀를 내밀었을 때 작살을 맞히면 포획이 쉬움 | 개구리 다리 + 개구리 가죽 |
| 3 | 물뱀 | 진흙물 속에 숨었다가 물결(예고) 뒤 튀어나와 물기. 숨었을 땐 안 맞음 | 뱀 살 + 뱀 비늘 |
| 4 | 박쥐 무리 | 어둠 속에서 떼로 돌진. 등불 빛을 싫어해 비추면 흩어짐 | 박쥐 날개 |
| 4 | 반딧버섯게 | 빛나는 버섯을 등에 진 게. 껍질이 단단해 뒤집거나 뒤에서만 잘 맞음 | 게살 + 게 껍데기·빛버섯 |

새 몬스터의 고기는 나중에 새 요리(레시피)로 이어진다(고깃집 설계와 별도 승인).

## 5. 연출·화면·서버·진행 순서 (설계 3/3)

### 5.1 손맛 연출 (데이브 수준)

- 층에 들어설 때 층 이름 카드("2층 · 깊은 숲").
- 포획: 줄이 팽팽하게 떨림, 원형 게이지, 연타마다 화면 흔들림, 성공하면 "포획!" 도장 + ★★ 튀어 오름.
- 재우기: 졸음 게이지 → 비틀 → 털썩 + Zzz, 담으면 ★★★ + 반짝이.
- 기력이 거의 없을 때 화면 가장자리가 붉게 깜빡이고 심장 소리(데이브의 산소 경고).
- 출구 방향 화살표, 가방이 꽉 차면 출구 쪽을 가리킴.
- 엄니대장 등장 이름 카드 컷인 + 화면 위 체력 막대, 깔아뭉개기 때 큰 연타 표시.
- 소리(Mixkit): 작살 발사, 줄 감기, 버둥, 포획, 코골이, 층 이동, 경고음. 내려받기 전에 목록을 보여 주고 허락받는다.
- 히트스톱·넉백·데미지 숫자는 그대로.

### 5.2 화면 표시

- 왼쪽 위: 기력 막대 + 층 이름. 오른쪽 아래: 작살·보조무기 아이콘과 남은 탄. 아래: 가방 칸 수와 도시락 칸. 일시정지 메뉴에 "자동 연타".
- 귀환 정산: 잡은 것을 별 등급별로 줄 세움.
- UI는 픽셀 키트로, 실제 화면(1280×720)을 찍어 확인한다.

### 5.3 서버 검증 (Verse8 규칙)

- 서버가 seed로 층별 몬스터·채집물을 다시 만들어 보고를 확인한다.
- 확인: 그 층에 맞는 장비가 있었는지, 몬스터를 한 번씩만 잡았는지, 잡는 방법별 최소 시간(포획 = 게이지 시간, 재우기 = 잠드는 시간, 층 이동 사이 시간), 수면총·그물총을 실제로 들고 들어갔는지와 쏜 탄 수, 출구로 나왔는지(출구 위치는 지도에 고정).
- 재료 개수·등급은 서버가 별 등급으로 계산한다. 별을 속이는 것은 위 상한으로만 묶는다(지금 특급 판정과 같은 수준).
- 하루 두 번 사냥은 서버의 날짜 단계(아침 사냥 → 점심 → 오후 사냥 → 저녁)로 막는다. 세 번째는 거절.
- 세이브: 새 필드(장비 단계, 보조무기, 깊은 층 재료, 오늘 몇 번째 사냥)는 Global User State의 세이브 하나에 `$lock`으로(지금 결정 그대로). 버전을 올리고 이전 세이브를 옮긴다.

### 5.4 진행 순서 (단계마다 배포)

1. **뼈대**: 층 이동, 기력, 출구, 하루 두 번, 서버 검증. 1·2층만, 그림은 지금 것.
2. **무기**: 보조무기 4종, 포획, 수면, 별 등급, 손맛 연출, 엄니대장.
3. **장비 업그레이드와 깊은 층 재료**: 장화·등불, 3·4층 규칙과 새 몬스터 4종.
4. **그림 전체 새로**: 층 배경 4장, 몬스터, 사냥꾼 동작. 그림마다 승인(PixelLab 충전 2026-10-28 이후도 이어서).
5. **보스**: 돌진대왕의 굴(03b).

고깃집 2단계(밤 장사) 계획은 이 사냥 1단계 다음에 짠다.

## 6. 테스트

- 공용 규칙 단위 테스트(vitest): 층 열기(장비 없으면 거부), 기력 감소(층별 속도·피격·도시락), 출구 귀환 검증, 하루 두 번(세 번째 거부), 별 → 재료 개수·등급, 수면총 없이 "재움" 거부, 탄 수 초과 거부, 방법별 최소 시간, 엄니대장 보상 2배, 같은 seed = 같은 층 배치, 세이브 마이그레이션(업그레이드 이어받기·환불).
- 서버 하네스(실행 전 사용자에게 알림).
- 브라우저 직접 플레이: PC(WASD·마우스·Space·E)와 모바일(조이스틱·버튼). 실제 화면을 찍어 사용자에게 보여 준다.
- 끝날 때마다 docs/VERSE8.md 점검표.
