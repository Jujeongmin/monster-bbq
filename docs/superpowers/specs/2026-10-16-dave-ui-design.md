# 데이브식 UI 재구성 설계

2026-10-16. 사용자: "UI 뜨는 것도 데이브 게임 참고해 지금 내 보유 아이템, 낮 밤 등 참고해서 다시 구성해."

## 1. 지금의 문제

- 자원 표시가 화면마다 다르다. 사냥 전·사냥 중·정산은 아래 가운데 막대, 점심·저녁 주방은 오른쪽 위 막대, 밤 장사는 가게 위쪽 막대와 아래 막대가 함께 뜬다.
- 아래 막대가 사냥 화면(무기 칸 옆)과 밤 장사 화면(가게 그림 위)을 가린다.
- 아래 막대의 "숯 0"은 결제 재화 황금 숯인데, 밤 장사의 숯 게이지와 이름이 겹친다.
- 보유 아이템은 "아이템 13" 숫자 하나뿐이다. 무엇을 가졌는지 보려면 주방 도감에 들어가야 한다.
- 지금이 하루 중 언제인지는 "낮 · 사냥" 글자로만 나온다.
- 사냥 출발과 정산은 빈 배경에 창 하나만 뜬다. 정산은 숫자를 한 줄로 늘어놓는다.

## 2. 결정 (사용자 2026-10-16, 네 가지 모두 추천안)

| 항목 | 결정 |
|---|---|
| HUD 구조 | 데이브식 단계별 HUD. 낮·주방·정산은 왼쪽 위 "시간대 그림 + N일째 · 시간대", 오른쪽 위 "골드 · 황금 숯(· VIP)". 사냥 중과 밤 장사 중에는 공용 HUD를 숨기고 그 장면 전용 HUD만 둔다. |
| 보유 아이템 | 가방 버튼 → 칸 격자 창. 탭은 고기·채집·재료. 칸마다 아이콘과 개수, 상급은 별. |
| 메뉴 모음 | 할머니 수첩 하나(데이브의 스마트폰). 수첩을 열면 가방·강화·각성·도감·메뉴판·상점이 앱 칸처럼 나온다. |
| 결과 화면 | 데이브식. 밤 정산은 영수증처럼 줄이 하나씩 올라오고 합계가 굴러간다. 사냥 귀환은 잡은 것이 한 칸씩 채워진다. 빈 배경 대신 가게 그림을 어둡게 깐다. |

## 3. 하루의 시간대

| 화면 | 시간대 | 공용 HUD |
|---|---|---|
| 아침 출발(보조무기 고르기) | 아침 | 보임 |
| 오전 사냥 중 | 아침 | 숨김(사냥 HUD) |
| 점심 주방 | 점심 | 보임 |
| 오후 사냥 중 | 오후 | 숨김(사냥 HUD) |
| 저녁 주방 | 저녁 | 보임 |
| 밤 장사 중 | 밤 | 숨김(가게 HUD) |
| 정산 | 밤 | 보임 |

시간대는 순수 함수 `timeOfDay(phase, huntPeriod)`로 정한다(테스트). 사냥 중이 아닌 `hunt` 단계는 아침이다(오후 출발 창은 점심 화면 위에 뜬다).

## 4. 화면 배치 (960×540 기준, `--s` 배율)

```
┌──────────────────────────────────────────────┐
│[☀ 2일째 · 점심]                 [● 1250][◆ 0]│
│                                              │
│                  (각 화면)                   │
│                                              │
│                                  [가방][수첩]│
└──────────────────────────────────────────────┘
```

- 왼쪽 위 판: 시간대 그림, "N일째 · 점심". 주방의 가게 이름 판(`환매 돌판집 · 점심 주방`)은 이 판 오른쪽에 붙인다.
- 오른쪽 위 막대: 골드, 황금 숯(이름을 "황금 숯"으로 바꿔 밤 장사 숯과 구분), VIP가 있으면 VIP.
- 오른쪽 아래: 가방·수첩 네모 버튼(`ui-sq`). 주방 아래 가운데 버튼 줄과 겹치지 않게 오른쪽 끝에 둔다.
- 사냥 중: 공용 HUD 전부 숨김. 사냥 HUD(초상화 기력 고리, 층·가방, 무기 칸)만.
- 밤 장사 중: 공용 HUD 전부 숨김. 가게 HUD(손님·골드·남은 그릇·시계, 주문 마감·일시정지)만.

## 5. 가방

- 수첩의 "가방" 칸이나 HUD 가방 버튼으로 연다. 탭 3개: 고기(`part`), 채집(`forage`), 재료(`material`).
- 칸 격자(`ui-slot`): 아이콘, ×개수. 상급 부위는 별(지금 `ItemIcon`과 같은 표시)이고, 같은 부위의 상급과 일반은 나란히 둔다(상급 먼저).
- 칸을 누르면 아래 설명 줄에 이름·등급·개수가 나온다.
- 빈 탭은 "아직 없어요" 한 줄.
- 정렬과 묶기는 순수 함수 `bagRows(items, kind)`(테스트): 아이템 표(`ITEMS`) 순서, 같은 부위는 상급 → 일반, 0개는 뺀다.

## 6. 할머니 수첩

- 앱 칸 6개: 가방, 강화, 각성, 도감, 메뉴판, 상점.
- 저녁 주방에서 도감·메뉴판은 주방의 그 탭으로 바꾼다. 다른 때에 도감은 읽기 전용(연구 버튼 잠김)으로 열리고, 메뉴판은 잠겨 "저녁 주방에서" 문구가 나온다.
- 강화·각성은 지금 업그레이드 창(`Upgrades`)을 그 탭으로 연다. 상점은 지금 VX 상점 창.
- 점심 화면의 "업그레이드" 버튼과 정산 창의 "업그레이드·상점" 버튼은 수첩으로 옮겨 없앤다. 사냥 귀환 창의 상점 버튼은 그대로 둔다.
- 어떤 칸이 열 수 있는지는 순수 함수 `notebookApps(phase)`(테스트).

## 7. 결과 화면

### 밤 정산 (영수증)

- 가게 그림을 어둡게 깔고 가운데에 영수증 종이.
- 줄: 응대한 손님 / 놓친 손님, 매출, 팁, 음료, 잔반 정리(있을 때만), 합계, 평판(변화량). 줄이 0.25초 간격으로 하나씩 나오고, 합계는 0에서 올라간다(0.8초).
- 화면을 누르면 연출을 건너뛰고 다 보인다. 버튼은 "다음 날" 하나.
- 줄 목록과 합계는 순수 함수 `receiptLines(lastService)`, 시간에 따른 진행은 `receiptAt(ms, lines)`(테스트).
- 요리별 매출은 세이브에 없다(서버 정산이 합계만 남김). 이번에는 합계만 보이고, 요리별은 서버 세이브를 바꿀 때 다시 정한다.

### 사냥 귀환

- 지금 `HuntSummary`의 내용(별 개수, 가져온 부위, 기절로 잃은 것, 열쇠·페이지)은 그대로 두고, 가져온 부위 칸이 0.12초 간격으로 하나씩 튀어나온다. 배경은 가게 그림을 어둡게.

### 아침 출발

- 보조무기 고르기 창 뒤에도 가게 그림을 어둡게 깐다(빈 화면 대신).

## 9. 바꾸지 않는 것

- 서버 규칙, 세이브 모양, 행동(Action). 이번 일은 화면만 바꾼다.
- 사냥 HUD(Phaser)와 밤 가게 HUD의 내용. 공용 HUD를 숨기는 것만 한다.
- 글은 전부 `t()`(ko·en 둘 다). CSS 색 상자로 새 창·버튼을 만들지 않고 UI 키트 그림을 쓴다.

## 10. 확인

- 순수 함수 테스트: `timeOfDay`, `bagRows`, `notebookApps`, `receiptLines`, `receiptAt`.
- 1280×720과 폰 가로(844×390)로 아침 출발, 사냥 중, 점심, 저녁 주방, 밤 장사, 정산을 찍어 본다. 공용 HUD가 사냥·장사 화면을 가리지 않고, 주방 버튼 줄과 가방·수첩 버튼이 겹치지 않는지 본다.
