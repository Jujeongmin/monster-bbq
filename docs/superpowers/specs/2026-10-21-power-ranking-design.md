# 전투력 랭킹 (2026-10-21)

## 왜

랭킹이 없으면 결제로 세져도 보여 줄 곳이 없다. 고액 결제자에게 돈 쓸 무대를 주고, 무료 유저에게도 숯 획득처를 준다.
사용자 결정(2026-10-21): 지표는 **전투력**(A), 이름은 **가게 이름 짓기**, **전투력 달성 보상** 넣기, 보스를 다시 잡아도 숯.

## 전투력 (shared/power.ts, 값은 `BALANCE.power`)

- **장비:** 업그레이드에서 산 레벨 합 × 100 + 장비 각성 별 합 × 150
- **요리:** 아는 요리마다 200 + 요리 레벨 × 100 + 요리 각성 별 × 150
- **옛 친구:** 일반 300 / 희귀 800 / 영웅 2,000 / 전설 5,000 × (1 + 별 × 0.1)
- **달성 보상:** 3,000 → 숯 5, 1만 → 10, 3만 → 20, 10만 → 50, 30만 → 100. 계정당 한 번씩이고, 모든 행동 뒤에 `applyAction`이 지급한다(`save.powerRewards`).

## 가게 이름

- 행동은 `nameShop { name }`, 공백을 뺀 1~15자이고 `save.shopName`에 저장한다.
- 이름이 없으면 랭킹에 "이름 없는 가게"로 나온다.

## 랭킹 (Verse8 Global Collection, 리더보드 문서 방식)

- **기록:** 컬렉션 `power`에 계정마다 한 줄 `{ account, name, power, vip, updatedAt }`(id = account)을 둔다.
  - 서버가 `act`·구매 웹훅에서 세이브가 바뀐 뒤 직접 계산해 쓴다. 이름·전투력·VIP가 바뀔 때만 쓰고, `load`에서도 한 번 쓴다.
  - 클라이언트가 점수를 보낼 길은 없다. 쓰는 함수는 Server 메서드가 아니라 모듈 함수라 원격으로 부를 수 없다.
  - 쓰기 실패는 저장을 막지 않는다(랭킹은 재화가 아님).
- **조회:** 원격 함수 `ranking()`이 상위 20줄(계정 id는 빼고, 내 줄 표시)과 내 순위(1 + 나보다 전투력이 높은 수, 동점은 같은 순위)를 준다.
- **초기화:** 없다. 전투력은 줄지 않는다. 주간 보상은 나중에 검토한다.

## 화면

- 날짜 판 옆에 "전투력 N"을 표시한다.
- 수첩에 **랭킹** 앱을 둔다(8번째 앱, "!"는 둘째 날부터, 처음 열 때 뚜껑이 한 줄).
- 책 창 왼쪽에는 1~20위(순위·이름·VIP·전투력)를 둔다.
- 오른쪽에는 이름 짓기, 내 전투력과 순위, 장비·요리·친구별 점수, 다음 달성 보상을 둔다.

## 보스 숯

- 돌진대왕 첫 처치는 50 그대로다. 그 뒤에는 처치마다 10을 준다.
- 엄니대장은 처치마다 3을 준다(`BALANCE.shop.bossRepeat`).

## 남은 것

- 랭킹 앱 아이콘 그림은 지금 반달이 대체 그림이다. 새 그림은 승인을 받아야 한다.
- 실제 Verse8 서버에서 여러 계정으로 확인해야 한다.
